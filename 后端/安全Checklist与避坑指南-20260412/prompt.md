# 安全 Checklist 与避坑指南

> 适用平台：所有 AI 编程工具
> 核心原则：永远不要使用你不理解的代码
> 参考来源：Auth0 Blog、OWASP Top 10、火山引擎社区、多位实践者经验

---

## 一、认证与授权 Checklist（每次必查）

```
[ ] JWT 算法是否明确指定？（algorithms=["RS256"] 或 ["HS256"]）
[ ] access_token 是否有短过期时间？（<= 15 分钟）
[ ] refresh_token 是否实现轮转？（每次使用后旧 token 失效）
[ ] 密码是否使用 bcrypt/Argon2 哈希？
[ ] 是否有速率限制防止暴力破解？
[ ] 用户身份是否从 token 提取（而非请求参数）？
[ ] OAuth 是否使用了正确的 flow？（Web: Auth Code + PKCE）
[ ] 是否验证了 redirect URI 白名单？
[ ] state 参数是否使用（防 CSRF）？
```

---

## 二、输入与输出 Checklist（每次必查）

```
[ ] 所有输入是否验证（类型、长度、格式）？
[ ] 是否使用参数化查询（防 SQL 注入）？
[ ] 错误信息是否对用户隐藏内部细节？
[ ] 是否设置了安全 Header？（CSP, X-Frame-Options, HSTS）
[ ] CORS 是否只允许可信来源（非 *）？
[ ] 日志中是否排除了 token 和密码？
[ ] 敏感数据是否加密存储？
```

---

## 三、部署 Checklist（上线前必查）

```
[ ] 所有密钥是否通过环境变量加载？
[ ] .env 是否加入 .gitignore？
[ ] NODE_ENV / ENV 是否设为 production？
[ ] 是否使用 HTTPS？
[ ] 是否配置了健康检查端点？
[ ] 是否有监控和告警？
```

## 四、AI 生成代码的常见错误

### 数据库相关

| 错误 | 解决方案 |
|------|---------|
| N+1 查询 | Prompt 中明确要求"使用 eager loading / joinedload" |
| 缺少数据库迁移 | 要求"所有 Schema 变更必须通过迁移脚本" |
| Float 存金额 | 强制"金额使用 Decimal 类型" |
| 忘记索引 | 要求"列出所有索引及添加理由" |

### API 相关

| 错误 | 解决方案 |
|------|---------|
| 缺少输入验证 | 要求"所有输入使用 Pydantic/class-validator 验证" |
| 错误处理不一致 | 要求"统一错误响应格式" |
| 缺少分页 | 要求"所有列表端点支持分页" |
| 缺少认证 | 要求"所有端点（除登录注册外）需要 JWT" |

### 安全相关

| 错误 | 解决方案 |
|------|---------|
| 硬编码密钥 | 明确"所有密钥通过环境变量加载" |
| SQL 注入 | 要求"必须使用参数化查询或 ORM" |
| CORS 为 * | 要求"CORS 仅允许指定来源" |

## 五、工作流层面的避坑

| 陷阱 | 症状 | 解决方案 |
|------|------|---------|
| **过度依赖 AI** | 不理解生成的代码就使用 | 黄金规则：永远不要使用你不理解的代码 |
| **上下文丢失** | AI 忘记之前的讨论 | 维护 plan.md + context.md + tasks.md 三文件 |
| **质量下降** | AI 输出越来越差 | 每次生成后运行 lint + 测试 |
| **技术债务累积** | 大量 TODO/FIXME | 每个阶段分配 20% 时间重构 |
| **大文件问题** | AI 写 500+ 行的文件 | 初始 Prompt 中植入 250 行上限规则 |
| **数据库被重置** | AI 误操作删表 | 迁移只增不删，生产数据定期备份 |
