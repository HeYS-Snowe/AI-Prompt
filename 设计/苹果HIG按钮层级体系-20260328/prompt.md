# 苹果 HIG 按钮层级体系

> **适用场景**：iOS / macOS / iPadOS 应用开发、类苹果风格 UI 设计
> **核心理念**：一个视图只突出一个动作，用形状 + 颜色 + 填充三维度表达层级
> **参考来源**：Apple Human Interface Guidelines

---

## 一、五级按钮层级

| 层级 | 样式 | 形状 | 填充 | 颜色 | 典型场景 |
|------|------|------|------|------|----------|
| **Primary** | Filled | 胶囊形 | 实心填充 | 品牌色 | 页面核心操作，每视图仅一个 |
| **Secondary** | Gray | 圆角矩形 | 浅灰填充 | 灰色系 | 辅助操作，可多个并列 |
| **Tertiary** | Tinted | 圆角矩形 | 品牌色浅底 | 品牌色低透明度 | 与主题色关联的辅助操作 |
| **Plain** | 纯文本 | 无形状 | 无背景 | 文字色 | 导航链接、行内操作 |
| **Destructive** | Red | 视上下文而定 | 红色填充/文字 | 红色 | 删除、移除等不可逆操作 |

---

## 二、核心设计规则

### 规则 1：唯一 Primary 原则

```
一个视图（View / Screen）中，Primary 按钮只能有一个。
当页面有多个"重要操作"时，只保留最重要的作为 Primary，
其余降级为 Secondary 或 Tertiary。
```

### 规则 2：弹窗特殊处理

```
在 Alert / Action Sheet 弹窗中：
- "确定/确认" → 胶囊形 + 品牌色（Primary 样式）
- "取消" → 胶囊形 + 灰色（Primary 形状 + Secondary 颜色）
- 两者都用胶囊形，因为弹窗场景下按钮数量有限（2-3 个）
```

### 规则 3：破坏性操作隔离

```
Destructive 操作（删除、清除、退出）：
- 不得使用 Primary 样式（不引导用户做危险操作）
- 使用红色文字或红色填充
- 必须配合二次确认弹窗
```

### 规则 4：按钮尺寸规范

```
最小可点击区域：
- iOS：44 × 44 pt
- Android：48 × 48 dp
- Web：无强制标准，建议 44 × 44 px

按钮高度推荐值：
- 大按钮：48-56px
- 标准按钮：36-44px
- 小按钮：28-32px
- 迷你按钮：24px（仅用于紧凑空间，如表格内）
```

### 规则 5：按钮间距

```
按钮组水平间距：12px（紧凑）/ 16px（标准）
按钮与内容间距：24px（上方）/ 16px（左右）
页面底部固定按钮距底部：16-20px
```

---

## 三、按钮状态

每个层级的按钮都应包含以下状态：

| 状态 | 视觉变化 | 交互方式 |
|------|----------|----------|
| **Normal** | 默认样式 | — |
| **Pressed** | 透明度降至 80% 或颜色加深 10% | 按下瞬间 |
| **Focused** | 外圈 2px 边框（键盘导航） | Tab 聚焦 |
| **Disabled** | 透明度 40%，禁止交互 | 灰色不可点击 |
| **Loading** | 隐藏文字，显示旋转图标 | 异步操作中 |

---

## 四、按钮图标规则

```
规则 1：图标仅用于增强辨识度，不替代文字标签
规则 2：图标在文字左侧（LTR 布局），间距 8px
规则 3：纯图标按钮仅用于 universally recognized 的图标（关闭、返回、更多）
规则 4：纯图标按钮必须提供 Tooltip 或 accessibility label
规则 5：图标尺寸 = 按钮高度 × 0.5（如 44px 按钮配 20px 图标）
```

---

## 五、常见场景决策树

```
这是一个破坏性操作吗？
├── 是 → 使用 Destructive 样式
└── 否 → 这是页面上最重要的操作吗？
          ├── 是 → 使用 Primary（胶囊）
          └── 否 → 这是一个辅助操作吗？
                    ├── 是 → 需要与品牌色关联吗？
                    │        ├── 是 → Tertiary（圆角矩形）
                    │        └── 否 → Secondary（灰色圆角矩形）
                    └── 否 → 使用 Plain（纯文本）
```
