# 知名网站设计系统参考目录

## 适用场景

- 需要快速确定一个项目的视觉风格方向时
- 想参考某类产品的设计语言时
- 组合多个网站的设计元素创建混合风格时
- 向 AI 描述"我要类似 XXX 的风格"时

## 使用方式

1. 根据项目类型在对应类别中查找风格相近的网站
2. 到 `D:\Code\.prompt\awesome-design-md-main\design-md\{网站名}\` 获取完整 DESIGN.md
3. 复制到项目根目录，或提取需要的章节使用
4. 也可直接告诉 AI："按照 {网站名} 的设计风格来生成界面"

## 风格速配指南

### 按氛围选择

| 想要的感觉 | 推荐网站 |
|------------|----------|
| **极简黑白、工程精确** | Vercel, Ollama, SpaceX, Uber |
| **暗色沉浸、开发者原生** | Linear, Supabase, Raycast, Warp |
| **温暖友好、人文关怀** | Notion, Airbnb, Wise, Cal.com |
| **高端奢侈、电影质感** | Apple, BMW, Stripe, Superhuman |
| **活力多彩、创意迸发** | Figma, Spotify, Framer, PostHog |
| **数据密集、专业仪表** | Sentry, Kraken, ClickHouse, Cohere |
| **紫色品牌、优雅科技** | Stripe, Linear, Mistral AI, Kraken |
| **绿色品牌、开源精神** | Supabase, VoltAgent, MongoDB, Wise |

### 按技术特征选择

| 技术特征 | 代表网站 |
|----------|----------|
| **极端负字间距** | Vercel (-2.88px), Notion (-2.125px), Apple (-0.374px) |
| **多层阴影系统** | Vercel (三层栈), Stripe (蓝调双层), Raycast (macOS 风格) |
| **shadow-as-border** | Vercel (0px 0px 0px 1px rgba) |
| **暗色原生设计** | Linear (#08090a), Supabase (#0f0f0f), Spotify (#121212) |
| **pill 按钮几何** | Spotify (9999px), Apple (980px), Supabase (9999px) |
| **零圆角/工业感** | BMW (0px radius) |
| **OpenType 特性驱动** | Stripe (ss01), Linear (cv01+ss03), Figma (kern) |
| **Weight 300 标题** | Stripe, BMW — 轻量标题传达"不需要喊叫的权威感" |
