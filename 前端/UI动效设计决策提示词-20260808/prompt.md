# UI 动效设计决策提示词（10 种动效分类体系）

> 2026-08-08 沉淀。来源：UI 动效设计教学视频内容提取（系统讲解 10 种常见 UI 动效：原理 + 作用 + 示例）。
> 定位：与 `动画设计审计清单-20260806`（emilkowalski 方法论，审查视角）互补——本文件是**设计选型视角**：从交互目的出发决定用什么动效。
> 配套 skill：`animation-vocabulary`（术语反向查找）、`animate`（动效实现）、`review-animations`（审查）。

## 一、核心价值（为什么需要动效）

动效不是让界面"动起来"，而是让**交互操作变得更清晰**：

| 价值 | 说明 |
|------|------|
| 用户引导 | 告诉用户下一步该看哪里、能做什么 |
| 感知度 | 强化用户对当前状态的理解（如输错密码时的反馈） |
| 交互清晰 | 让操作结果可预期、可理解 |
| 体验必需 | 动效已成为用户体验中不可或缺的一部分 |

> 判断基准：如果一个动效删掉后用户会困惑、操作不明确——它就是必要的；如果只是好看——按频率规则（高频不做）审视。

## 二、10 种 UI 动效分类总表

| # | 动效 | 原理 | 作用 | 典型示例 |
|---|------|------|------|----------|
| 1 | **缓动 Easing** | 元素运动时缓慢加速/减速，而非生硬匀速 | 避免突兀感，增强视觉自然感 | 商品卡片平滑切换 |
| 2 | **视差 Parallax** | 多个元素以不同速度运动 | 构建层次感与深度 | 文章页滚动时背景图与前景文字速度不同 |
| 3 | **偏移和延迟 Offset & Delay** | 多个内容同时移动时，在时间/位置上交错间隔 | 运动有节奏感，增强活力 | 评论区列表项依次有序滑入 |
| 4 | **遮罩 Masking** | 用特定形状改变元素（如图片）的显示区域 | 强化视觉焦点，提高掌控感，增强页面关联 | 点圆形缩略图→图片以形状展开至全屏 |
| 5 | **数值变化 Value Change** | 把数字的变化过程动态化展示 | 清晰感知数据变化与趋势 | "5"→"49" 动态跳变计数 |
| 6 | **父子级 Parenting** | 建立层级关系，父属性变化时子元素协同变化 | 元素间协同互动 | 温控器拖动外圈滑块（父），内部温度数字/状态（子）同步 |
| 7 | **叠加 Overlay** | 一层信息覆盖在原有内容之上 | 拉开前后景深区分，增强扁平空间的层次；展示暂时隐藏的内容 | 点商品图→侧滑出筛选面板（尺码/颜色） |
| 8 | **形态转换 Transformation** | UI 元素样式无缝过渡到另一状态 | 保持视觉连贯性 | 一组色块合并成一个带确认标记的色块 |
| 9 | **滑动和缩放 Dolly & Zoom** | 对视图元素可视化移动或缩放 | 体现内容元素在空间上的关系 | 从 App 图标主页放大过渡到内容详情页 |
| 10 | **克隆 Cloning** | 一个 UI 元素分裂/复制成其他元素 | 丰富展现方式，描述内容间关联 | 社交卡片按钮点击后分裂出多个操作图标 |

**补充概念：维度（Dimension）**——UI 设计可不局限于二维平面，增加维度（如 3D 翻转）让设计更有趣味性。示例：音乐播放器封面点击后 3D 翻转显示歌词。

## 三、目的 → 选型决策表（可复用提示词核心）

设计动效时**不要从动效清单里挑**，而是先回答"我要解决什么"，再选型：

| 设计目的 | 首选动效 | 备选 | 关键实现点 |
|----------|----------|------|-----------|
| 消除突变/生硬过渡 | 缓动 Easing | 形态转换 | 强缓动曲线（ease-out），禁用匀速 |
| 建立空间层次/深度 | 视差 Parallax | 滑动和缩放 Dolly & Zoom | 不同层不同速度系数 |
| 多元素入场要有节奏 | 偏移和延迟 Offset & Delay | — | 30~80ms 交错间隔，1 项 = 1 步 |
| 聚焦视觉焦点 | 遮罩 Masking | 叠加 Overlay | 形状展开 + 圆角过渡 |
| 展示数据变化 | 数值变化 Value Change | — | 数字补间 + tabular-nums 防跳动 |
| 关联元素协同 | 父子级 Parenting | 克隆 Cloning | 父变换 → 子跟随（transform 层级） |
| 展示隐藏内容 | 叠加 Overlay | — | 层叠 + 模糊/阴影区分景深 |
| 状态间无缝衔接 | 形态转换 Transformation | 滑动和缩放 Dolly & Zoom | 共享元素/布局动画 |
| 表达空间关系/导航 | 滑动和缩放 Dolly & Zoom | 视差 | 缩放过渡 + 方向一致 |
| 展示内容关联/分裂 | 克隆 Cloning | — | 源元素 → 多目标 |
| 趣味性/记忆点（低频） | 维度（3D 翻转） | — | 仅限低频、首次出现场景 |

**铁律**（与审计清单一致）：
- 高频操作（100+/天）→ 不做或近不可感
- 所有动效只用 `transform` + `opacity`（GPU 合成）
- 进入/退出用 `ease-out`，屏内移动用 `ease-in-out`，UI 时长 <300ms
- 手势/可中断动效用弹簧（spring），不用 keyframes
- 必须带 `prefers-reduced-motion` 降级

## 四、可复用提示词模板

### 4.1 动效选型提示词（设计阶段）

```text
你是 UI 动效设计师。为以下交互选择并实现动效，遵循"目的→选型"决策：

【交互描述】<粘贴交互场景，如：用户点击商品卡片进入详情页>
【交互频率】<高频/偶尔/低频首次>（高频禁用或极简，低频可加 delight）
【设计目的】<从下列选：消除突变 / 建立层次 / 入场节奏 / 聚焦焦点 / 数据感知 / 元素协同 / 展示隐藏内容 / 状态衔接 / 空间关系 / 内容分裂 / 趣味维度>

按此决策：
1. 从「目的→选型决策表」选出首选动效（必要时备选组合）
2. 给出实现要点：缓动曲线、时长（UI<300ms）、交错的间隔（30~80ms）
3. 只动 transform/opacity；进入/退出 ease-out，屏内移动 ease-in-out
4. 手势可中断用 spring；高频场景直接去掉动画
5. 附带 prefers-reduced-motion 降级方案

输出：动效清单（每条：动效名 + 实现要点 + 时长/曲线 + 降级）。
```

### 4.2 动效审查提示词（对照本分类）

```text
审查以下界面的动效设计，按 10 种动效分类检查：
1. 每个动效属于哪一类？目的明确吗（引导/感知/清晰/体验）？
2. 有没有"为动而动"的（无目的、高频场景）？
3. 缺漏检查：突变处该有缓动吗？数据变化该有数值动效吗？多元素入场该有交错吗？
4. 实现合规：只动 transform/opacity？时长 <300ms？ease-out/ease-in-out？reduced-motion？
输出：问题清单（位置 + 分类 + 问题 + 建议）。
```

### 4.3 从零构建动效方案提示词（新页面）

```text
为以下页面/组件设计完整动效方案（目的驱动，非装饰）：
<页面描述>
覆盖检查点：
- 入场：多元素需 Offset & Delay 交错；层级用 Parallax
- 状态反馈：按钮按压、表单错误（Value Change 或缓动反馈）
- 导航：Dolly & Zoom 表达空间关系；方向一致进出
- 隐藏内容：Overlay 面板；Masking 展开焦点
- 关联元素：Parenting 协同；数据用 Value Change
- 连贯性：状态切换用 Transformation（共享元素）
每个动效注明：分类 + 目的 + 时长/曲线 + reduced-motion 降级。
```

## 五、设计要点速查

- **动效四价值**：引导 / 感知 / 清晰 / 体验——任何动效必须命中至少一个
- **10 分类口诀**：缓视偏遮数，父叠形滑克（缓动/视差/偏移延迟/遮罩/数值变化 / 父子/叠加/形态转换/滑动缩放/克隆）
- **维度概念**：2D 平面之外可加 3D（翻转/纵深），只在低频、首次、纪念性场景用
- **配套文档**：实现细节 → `animate` skill；术语 → `animation-vocabulary`；审查 → `动画设计审计清单-20260806` + `review-animations` skill
