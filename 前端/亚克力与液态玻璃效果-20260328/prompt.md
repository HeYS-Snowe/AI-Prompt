# 亚克力与液态玻璃效果

> 适用平台：Flutter / 移动端应用

---

## 亚克力背景模糊（Acrylic Blur）

所有半透明面板、侧边栏、弹窗、卡片均采用亚克力模糊效果。

### 实现方式

- 使用 `BackdropFilter` + `ImageFilter.blur` 实现

### 模糊层级规范

| 层级  | 应用场景                       | 模糊强度       |
| --- | -------------------------- | ---------- |
| 背景层 | 页面大背景、底部装饰                 | 轻度 10-15px |
| 面板层 | 卡片、侧边栏、导航栏                 | 中度 20-30px |
| 弹窗层 | Dialog、BottomSheet、Tooltip | 重度 30-40px |

### 材质叠加

- 亚克力表面叠加极低透明度的纯色色调（约 5%-15%），增强材质感
- 必须支持深色/浅色两套亚克力色调自动切换

### Flutter 示例

```dart
BackdropFilter(
  filter: ImageFilter.blur(sigmaX: 20, sigmaY: 20),
  child: Container(
    decoration: BoxDecoration(
      color: Colors.white.withOpacity(0.1),
      borderRadius: BorderRadius.circular(16),
      border: Border.all(color: Colors.white.withOpacity(0.2)),
    ),
  ),
)
```

## 液态玻璃效果（Liquid Glass）

关键交互元素（按钮、输入框、导航栏）采用液态玻璃质感。

### 视觉特征

- **高透明度**：背景内容隐约可见
- **动态折射边缘**：边缘带有光线折射感
- **内部光线流动**：有微妙的光线在玻璃内部流动
- **高光描边**：边缘使用 1px 半透明白色描边模拟玻璃高光
- **渐变色块叠加**：内部可叠加微妙的渐变色块模拟光线折射

### 交互状态

| 状态  | 变化              |
| --- | --------------- |
| 默认态 | 标准液态玻璃质感        |
| 按下态 | 玻璃产生轻微形变 + 光泽变亮 |
| 悬浮态 | 边缘高光增强 + 轻微发光   |
| 焦点态 | 边缘高亮强调色描边       |
| 禁用态 | 降低透明度 + 去除光泽动效  |

### 注意事项

- 液态玻璃效果不要过度使用，仅限关键交互元素
- 确保文字在玻璃表面上的可读性（添加文字阴影或背景遮罩）
- 性能敏感区域（长列表项）慎用，可用简化版玻璃效果替代
