# 高级动效设计规范

> 适用平台：Flutter / 移动端应用
> 核心原则：丝滑流畅，60fps，克制不滥用

---

## 动画曲线（统一使用 Material Motion 曲线族）

| 曲线                      | 适用场景       | 特点        |
| ----------------------- | ---------- | --------- |
| `Curves.easeOutCubic`   | 页面打开、元素进入  | 快速启动、柔和减速 |
| `Curves.easeInCubic`    | 页面关闭、元素退出  | 缓慢启动、柔和停止 |
| `Curves.easeOutBack`    | 卡片弹入（轻微过冲） | 弹性过冲、活泼感  |
| `Curves.elasticOut`     | 按钮点击回弹     | 弹性形变回弹    |
| `Curves.easeInOutQuart` | 状态切换过渡     | 两端柔和      |
| `Curves.decelerate`     | 滑动减速       | 自然减速      |

---

## 一、窗口动效

### 页面打开

- 轨迹：从屏幕底部向上滑入 + 淡入
- 时长：300-400ms
- 曲线：`Curves.easeOutCubic`

### 页面关闭

- 轨迹：向底部滑出 + 淡出
- 时长：250-350ms
- 曲线：`Curves.easeInCubic`

### 弹窗出现

- 轨迹：缩放 0.85 → 1.0 + 淡入
- 时长：250ms
- 曲线：`Curves.easeOutBack`
- 遮罩：同步淡入，颜色 `Colors.black26`

### 弹窗关闭

- 轨迹：缩放 1.0 → 0.95 + 淡出
- 时长：200ms
- 曲线：`Curves.easeInCubic`
- 遮罩：同步淡出

---

## 二、点击动效

### 按钮/卡片

- 按下：缩小至 0.96 + 颜色加深 10%
- 松开：弹性回弹至 1.0
- 曲线：`Curves.elasticOut`，时长 300ms

### 涟漪效果（Ripple）

- 从点击位置向外扩散水波纹
- 颜色：取当前主题色的 20% 透明度版本
- 时长：400ms

### 图标点击

- 微旋转（5-10度）+ 缩放（0.9 → 1.0）回弹组合
- 时长：200ms

### 开关/切换

- 平滑滑动 + 颜色渐变过渡
- 时长：250ms
- 曲线：`Curves.easeInOutQuart`

---

## 三、页面切换动效

### Tab 切换

- 内容区域水平滑动 + 指示器弹性跟随
- 时长：300ms
- 曲线：`Curves.easeOutCubic`
- 指示器可使用弹簧效果

### 底部导航切换

- 当前页面淡出 + 新页面淡入
- 可叠加轻微缩放（0.98 → 1.0）
- 时长：250ms

### 路由跳转（Hero 动画）

- 前后页面共享元素通过 Hero 动画连接
- 非共享元素依次错开 50ms 进入
- 确保共享元素在两个页面中的 Widget 类型一致

---

## 四、元素载入/载出动效

### 列表项载入

- 依次从下方滑入 + 淡入
- 每项延迟 50-80ms（stagger 效果）
- 单项时长：300ms

### 卡片载入

- 缩放 0.9 → 1.0 + 淡入
- 曲线：`Curves.easeOutBack`（轻微过冲增加活力）
- 时长：350ms

### 文字载入

- 逐行淡入（按需使用，不滥用）
- 每行延迟 80-100ms
- 时长：250ms

### 元素移除

- 缩小至 0.8 + 淡出
- 时长：200ms
- 曲线：`Curves.easeInCubic`

### 骨架屏

- 脉冲闪烁动画（Shimmer）
- 频率：每 1.5s 一个周期
- 从骨架屏过渡到真实内容：交叉淡入淡出，时长 300ms

### 下拉刷新

- 自定义弹性回弹动画
- 拉动时跟随手指，松手后弹性回弹
- 使用 `Curves.elasticOut`

---

## 五、全局动效原则

1. 所有动画时长控制在 **150-500ms**，不超过 600ms
2. 必须保持 **60fps**，复杂动画使用 `RepaintBoundary` 隔离
3. 尊重系统 `reduceMotion` 无障碍设置
4. 避免同一时刻执行过多动画（最多 3 个并行动画元素）
5. 动画曲线定义在统一常量文件中，全局复用
6. 列表动效使用 `AnimatedBuilder` + `ScrollController` 实现滚动触发
