# Flutter 移动端高级 UI 设计规范（完整版）

> 适用平台：Flutter / 移动端应用
> 角色定位：与 UI 设计师智能体协同重构前端设计

---

## 设计理念

采用 **扁平化设计** 为基调，融合 **亚克力材质** 与 **液态玻璃拟态**，打造现代、高级、通透的视觉体验。所有界面必须兼顾清晰美观的布局、明确的分类层级、统一且高级的配色风格，以及丝滑流畅的动效体系。

---

## 一、材质与背景

### 亚克力背景模糊（Acrylic Blur）

- 所有半透明面板、侧边栏、弹窗、卡片均采用亚克力模糊效果
- 使用 `BackdropFilter` + `ImageFilter.blur` 实现
- 模糊层级：背景层（轻度 10-15px）、面板层（中度 20-30px）、弹窗层（重度 30-40px）
- 亚克力表面叠加极低透明度的纯色色调（约 5%-15%），增强材质感
- 支持深色/浅色两套亚克力色调

### 液态玻璃效果（Liquid Glass）

- 关键交互元素（按钮、输入框、导航栏）采用液态玻璃质感
- 特征：高透明度 + 动态折射边缘 + 内部光线流动感
- 边缘使用 1px 半透明白色描边模拟玻璃高光
- 内部可叠加微妙的渐变色块模拟光线折射
- 交互时（按下/悬浮）玻璃质感产生形变与光泽变化

## 二、动效体系（丝滑流畅）

### 窗口动效

- 页面打开：从屏幕底部滑入 + 淡入，时长 300-400ms，曲线 `Curves.easeOutCubic`
- 页面关闭：向底部滑出 + 淡出，时长 250-350ms，曲线 `Curves.easeInCubic`
- 弹窗出现：缩放从 0.85 到 1.0 + 淡入，时长 250ms
- 弹窗关闭：缩放从 1.0 到 0.95 + 淡出，时长 200ms

### 点击动效

- 按钮/卡片点击：按下缩小至 0.96 + 颜色加深，松开弹性回弹至 1.0，曲线 `Curves.elasticOut`
- 涟漪效果（Ripple）：点击位置扩散水波纹，颜色取主题色 20% 透明度
- 图标点击：微旋转 + 缩放回弹组合
- 开关/切换：平滑滑动 + 颜色渐变过渡

### 页面切换动效

- Tab 切换：内容区域水平滑动 + 指示器弹性跟随，时长 300ms
- 底部导航切换：当前页面淡出 + 新页面淡入，可叠加轻微缩放
- 路由跳转：Hero 动画连接前后页面共享元素，非共享元素依次错开进入

### 元素载入/载出动效

- 列表项：依次从下方滑入 + 淡入，每项延迟 50-80ms（stagger）
- 卡片：缩放从 0.9 到 1.0 + 淡入，曲线 `Curves.easeOutBack`（轻微过冲）
- 文字：逐行/逐字淡入（按需使用，不滥用）
- 元素移除：缩小 + 淡出，时长 200ms
- 骨架屏加载：脉冲闪烁过渡到真实内容
- 下拉刷新：自定义弹性回弹动画

### 全局动效原则

- 所有动画曲线统一使用 Material Motion 推荐曲线族
- 动画时长控制在 150-500ms，不超 600ms
- 尊重系统 `reduceMotion` 无障碍设置
- 避免同时执行过多动画，保持 60fps

## 三、配色方案

### 核心原则

- **严禁使用** Tailwind 默认紫色到蓝紫色对角渐变配色（已过时 5 年）
- 推荐配色方案（按风格分类，按需选用）：

### 方案 A：深邃墨绿 + 琥珀金

- 主色：`#1A2F23` / `#2D4A3E`
- 强调色：`#D4A843` / `#F0C75E`
- 辅助色：`#4A7C6F` / `#8FB8A3`

### 方案 B：石墨黑 + 珊瑚橘

- 主色：`#1C1C1E` / `#2C2C2E`
- 强调色：`#FF6B4A` / `#FF8F73`
- 辅助色：`#3A3A3C` / `#636366`

### 方案 C：深海蓝绿 + 薄荷

- 主色：`#0D1B2A` / `#1B3A4B`
- 强调色：`#00D9A6` / `#4ECDC4`
- 辅助色：`#1A3C5E` / `#3D7EA6`

### 方案 D：暖灰 + 玫瑰金

- 主色：`#F5F0EB` / `#E8E0D8`（浅色模式）
- 强调色：`#B76E79` / `#D4A088`
- 辅助色：`#C4B5A5` / `#8C7B6B`

### 渐变效果使用规范

渐变不仅仅是全区域对角渐变，应根据场景灵活运用：

| 渐变类型      | 说明                 | 适用场景        |
| --------- | ------------------ | ----------- |
| 全区域渐变     | 渐变铺满整个目标元素         | 大背景、横幅      |
| 半区域渐变     | 渐变只覆盖元素的一部分（如下半部分） | 卡片底部、头部区域   |
| 多色渐变      | 同一元素内叠加多个渐变色       | 高级按钮、装饰条    |
| 边角点缀渐变    | 渐变只填充边角做装饰         | 卡片角落光晕、头像边框 |
| 径向渐变      | 从中心向外扩散            | 聚光灯效果、焦点区域  |
| 线性渐变（非对角） | 水平、垂直、任意角度         | 进度条、分割线装饰   |

## 四、布局规范

### 整体布局原则

- 信息层级清晰：主内容 > 辅助信息 > 装饰元素
- 分类明确：功能区域通过留白、分隔线、色块进行视觉分组
- 内容呼吸感：合理的内边距与外边距，避免拥挤
- 对齐系统：统一 4px / 8px 网格对齐
- 响应式适配：适配不同屏幕尺寸（手机、平板）

### 导航结构

- 顶部导航栏：亚克力材质 + 液态玻璃效果
- 底部导航栏：图标 + 文字，选中态带液态玻璃高光
- 侧边栏（平板）：亚克力模糊面板，支持手势展开/收起

### 卡片与面板

- 卡片使用圆角（12-16px）+ 轻微阴影
- 卡片表面使用亚克力材质
- 卡片之间保持均匀间距（12-16px）
- 列表卡片支持滑动操作

## 五、粒子与微元素

### 适用场景（不滥用）

- 空状态页面背景
- 加载等待页面
- 特殊节日/活动主题
- 个人中心头部背景

### 粒子效果规范

- 粒子数量控制在 20-50 个，避免性能问题
- 粒子大小：1-4px，带模糊效果
- 粒子运动：缓慢漂浮 + 轻微随机扰动
- 粒子颜色：取当前页面主色或强调色的低透明度版本
- 粒子形状：圆形为主，可少量混入菱形、三角形

### 微元素

- 几何线条装饰
- 光斑/光晕效果
- 网格点阵（低透明度背景纹理）
- 流动渐变色块（极低透明度）

## 六、技术实现要点（Flutter）

```dart
// 亚克力模糊面板示例
BackdropFilter(
  filter: ImageFilter.blur(sigmaX: 20, sigmaY: 20),
  child: Container(
    decoration: BoxDecoration(
      color: Colors.white.withOpacity(0.1),
      borderRadius: BorderRadius.circular(16),
      border: Border.all(color: Colors.white.withOpacity(0.2)),
    ),
  ),
)
```

- 使用 `flutter_animate` 或 `animations` 包实现复杂动效
- 使用 `CustomPaint` + `Canvas` 绘制粒子效果
- 使用 `ShaderMask` + `LinearGradient` 实现各类渐变
- 性能优化：粒子效果使用 `RepaintBoundary` 隔离重绘区域
- 全局动画曲线定义在统一常量文件中
