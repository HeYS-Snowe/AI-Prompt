# 网页表面风格

> 网页表层视觉处理流派:玻璃、黏土、扁平、材质、便当盒等。决定页面第一眼的质感与触感。
>
> 共 20 种风格。每种含:精髓 / 配色 / 字体 / 视觉特征 / 复刻要点 / 即用 Prompt,并附配套实践 demo 路径。
> 配色与字体仅供快速参考,完整数据见根目录 `styles.json`(机器可读,AI 可直接引用)。

### 1. Glassmorphism · 玻璃拟态
> 年代 2020+　·　关键词:毛玻璃 frosted glass backdrop-filter

**精髓**:半透明面板叠在高斯模糊的背景之上，带 1px 高光描边，背后内容若隐若现，呈现磨砂玻璃质感。

**配色 Palette**: `#ffffff` `#7f5cff` `#ff6ec7` `#1a1a2e`

**推荐字体**:`Inter / SF Pro Text（清晰无衬线，弱字重对比）`

**视觉特征**

- 背景需有彩色色块/图片，否则玻璃无内容可透
- 面层 fill 用 rgba(255,255,255,.08~.18)，深色用 rgba(255,255,255,.06)
- 统一描边 1px rgba(255,255,255,.18~.25) 模拟玻璃高光
- 文字需加细微文字阴影或暗遮罩保证可读性

**复刻要点**

- backdrop-filter: blur(20px) saturate(140%); 配 -webkit-backdrop-filter
- 卡片圆角 16~20px，阴影用多层柔光
- Flutter：BackdropFilter + ImageFilter.blur(sigmaX:20)
- 勿滥用——长列表/表格里用会卡且脏，仅用于弹窗、控制中心、导航栏

**范例与适用**:macOS Big Sur 起、iOS 控制中心、Microsoft Fluent Acrylic、Linear 部分浮层、本地 prompt 库《亚克力与液态玻璃效果》。

**即用 Prompt**

```text
Build a page in "Glassmorphism" (玻璃拟态) style. 半透明面板叠在高斯模糊的背景之上，带 1px 高光描边，背后内容若隐若现，呈现磨砂玻璃质感。 Visual: 背景需有彩色色块/图片，否则玻璃无内容可透; 面层 fill 用 rgba(255,255,255,.08~.18)，深色用 rgba(255,255,255,.06); 统一描边 1px rgba(255,255,255,.18~.25) 模拟玻璃高光; 文字需加细微文字阴影或暗遮罩保证可读性. Replicate: backdrop-filter: blur(20px) saturate(140%); 配 -webkit-backdrop-filter; 卡片圆角 16~20px，阴影用多层柔光; Flutter：BackdropFilter + ImageFilter.blur(sigmaX:20); 勿滥用——长列表/表格里用会卡且脏，仅用于弹窗、控制中心、导航栏. Palette: #ffffff, #7f5cff, #ff6ec7, #1a1a2e. Font: Inter / SF Pro Text（清晰无衬线，弱字重对比）.
```

### 2. Neumorphism · 新拟态 / Soft UI
> 年代 2019　·　关键词:柔和浮雕 soft UI 双向阴影

**精髓**:背景与组件同色，用「亮+暗」双向柔光阴影制造凸起或凹陷，像在软橡皮上压出来的物理按键。

**配色 Palette**: `#e0e5ec` `#9fa6b8` `#4a4f5c` `#5a7bff`

**推荐字体**:`Quicksand / Nunito（圆润几何无衬线）`

**视觉特征**

- 背景必须接近组件色，否则浮雕消失
- 凸起：box-shadow 同时给 -6,-6,12 #fff 与 6,6,12 rgba(0,0,0,.12)
- 凹陷：改用 inset 阴影
- 圆角偏大（14~20px），交互常为「按下变凹陷」

**复刻要点**

- 核心：亮阴影 #ffffff + 暗阴影 rgba(163,177,198,.6)
- 配色限单色系，靠阴影而非颜色区分层级
- 缺点：可访问性差，按钮与背景对比度低，勿用于需高对比的表单

**范例与适用**:UI8 Soft UI Dashboard、Alexander Plyuto 原型、部分智能硬件控制面板。

**即用 Prompt**

```text
Build a page in "Neumorphism" (新拟态 / Soft UI) style. 背景与组件同色，用「亮+暗」双向柔光阴影制造凸起或凹陷，像在软橡皮上压出来的物理按键。 Visual: 背景必须接近组件色，否则浮雕消失; 凸起：box-shadow 同时给 -6,-6,12 #fff 与 6,6,12 rgba(0,0,0,.12); 凹陷：改用 inset 阴影; 圆角偏大（14~20px），交互常为「按下变凹陷」. Replicate: 核心：亮阴影 #ffffff + 暗阴影 rgba(163,177,198,.6); 配色限单色系，靠阴影而非颜色区分层级; 缺点：可访问性差，按钮与背景对比度低，勿用于需高对比的表单. Palette: #e0e5ec, #9fa6b8, #4a4f5c, #5a7bff. Font: Quicksand / Nunito（圆润几何无衬线）.
```

### 3. Claymorphism · 黏土拟态
> 年代 2021　·　关键词:膨胀黏土 clay puffy 内阴影

**精髓**:大圆角膨胀体 + 彩色柔光 + 明显内阴影高光，像捏出来的彩色橡皮泥，圆润、Q弹、童趣。

**配色 Palette**: `#ff6b9d` `#ffd166` `#6ec1e4` `#8b5cf6`

**推荐字体**:`Poppins / Quicksand（粗壮圆体）`

**视觉特征**

- 圆角极大（24~40px），造型「鼓鼓的」
- 内阴影 inset 偏移制造顶部高光，外阴影柔和
- 饱和但不刺眼的马卡龙色
- 按钮常有「悬浮感」，按下时阴影收缩

**复刻要点**

- box-shadow: inset 0 -8px 16px rgba(0,0,0,.12), inset 0 6px 12px rgba(255,255,255,.6), 0 12px 24px rgba(0,0,0,.12)
- 半径统一偏大，深色基底配浅色高光
- 适合玩具/儿童/创意产品，严肃后台慎用

**范例与适用**:Spline 首页插画风组件、部分 Figma 插件、儿童教育 App。

**即用 Prompt**

```text
Build a page in "Claymorphism" (黏土拟态) style. 大圆角膨胀体 + 彩色柔光 + 明显内阴影高光，像捏出来的彩色橡皮泥，圆润、Q弹、童趣。 Visual: 圆角极大（24~40px），造型「鼓鼓的」; 内阴影 inset 偏移制造顶部高光，外阴影柔和; 饱和但不刺眼的马卡龙色; 按钮常有「悬浮感」，按下时阴影收缩. Replicate: box-shadow: inset 0 -8px 16px rgba(0,0,0,.12), inset 0 6px 12px rgba(255,255,255,.6), 0 12px 24px rgba(0,0,0,.12); 半径统一偏大，深色基底配浅色高光; 适合玩具/儿童/创意产品，严肃后台慎用. Palette: #ff6b9d, #ffd166, #6ec1e4, #8b5cf6. Font: Poppins / Quicksand（粗壮圆体）.
```

### 4. Liquid Glass · 液态玻璃
> 年代 2025　·　关键词:液态玻璃 折射 Apple vision

**精髓**:Apple 2025 提出的下一代材质：比玻璃拟态更通透，边缘有动态光线折射，玻璃内部似有光在流动，像真实镜片。

**配色 Palette**: `#0a0a0f` `#ffffff` `#0a84ff` `#ffd60a`

**推荐字体**:`SF Pro（与系统一致）`

**视觉特征**

- 极高透明度，背景内容近乎可辨
- 边缘动态折射高光，随内容流动
- 1px 半透明白描边 + 内部微妙渐变色块
- 镜片随圆角贴合内容，形成动态高光带

**复刻要点**

- backdrop-filter: blur(24px) saturate(180%) contrast(1.05)
- 叠加 conic/linear 渐变模拟折射，mix-blend-mode: overlay
- 边缘 box-shadow inset 高光 + 伪元素流光动画
- 可读性靠深色文字 + 浅毛玻璃，或浅文字 + 深毛玻璃

**范例与适用**:iOS 26 / iPadOS 26 / macOS Tahoe（2025 WWDC）、visionOS 2、Apple 官方 Liquid Glass 设计指南。

**即用 Prompt**

```text
Build a page in "Liquid Glass" (液态玻璃) style. Apple 2025 提出的下一代材质：比玻璃拟态更通透，边缘有动态光线折射，玻璃内部似有光在流动，像真实镜片。 Visual: 极高透明度，背景内容近乎可辨; 边缘动态折射高光，随内容流动; 1px 半透明白描边 + 内部微妙渐变色块; 镜片随圆角贴合内容，形成动态高光带. Replicate: backdrop-filter: blur(24px) saturate(180%) contrast(1.05); 叠加 conic/linear 渐变模拟折射，mix-blend-mode: overlay; 边缘 box-shadow inset 高光 + 伪元素流光动画; 可读性靠深色文字 + 浅毛玻璃，或浅文字 + 深毛玻璃. Palette: #0a0a0f, #ffffff, #0a84ff, #ffd60a. Font: SF Pro（与系统一致）.
```

### 5. Flat 2.0 / Material · 扁平化 2.0
> 年代 2014+　·　关键词:扁平 subtle shadow 层次

**精髓**:在纯扁平基础上加入微妙阴影、层级与深度暗示，保留扁平的干净，又比无修饰更可读、更有触感。

**配色 Palette**: `#ffffff` `#f5f5f7` `#1d1d1f` `#0071e3`

**推荐字体**:`SF Pro / Roboto（中性无衬线）`

**视觉特征**

- 无渐变、无纹理、无拟物，靠阴影分层
- 阴影极柔：0 1px 2px rgba(0,0,0,.06) 起步
- 强调色单一克制，多为品牌蓝
- 大留白 + 几何排版

**复刻要点**

- box-shadow 分 2~3 级 sm/md/lg，颜色一律低透明度黑
- 圆角 6~12px，按钮/卡片统一
- 配色：白底 + 深灰文字 + 单一品牌强调色
- Google Material Elevation 是参考标准

**范例与适用**:Apple 官网、Google Material Design、Microsoft Fluent 轻量态、大多数现代 SaaS。

**即用 Prompt**

```text
Build a page in "Flat 2.0 / Material" (扁平化 2.0) style. 在纯扁平基础上加入微妙阴影、层级与深度暗示，保留扁平的干净，又比无修饰更可读、更有触感。 Visual: 无渐变、无纹理、无拟物，靠阴影分层; 阴影极柔：0 1px 2px rgba(0,0,0,.06) 起步; 强调色单一克制，多为品牌蓝; 大留白 + 几何排版. Replicate: box-shadow 分 2~3 级 sm/md/lg，颜色一律低透明度黑; 圆角 6~12px，按钮/卡片统一; 配色：白底 + 深灰文字 + 单一品牌强调色; Google Material Elevation 是参考标准. Palette: #ffffff, #f5f5f7, #1d1d1f, #0071e3. Font: SF Pro / Roboto（中性无衬线）.
```

### 6. Material You (M3) · Material 3
> 年代 2021　·　关键词:材质你 动态色彩 大圆角

**精髓**:Google 新一代设计语言：从壁纸提取动态配色，圆角更夸张，组件更软，强调个性与情感。

**配色 Palette**: `#6750a4` `#eaddff` `#21005d` `#625b71`

**推荐字体**:`Roboto / Google Sans`

**视觉特征**

- 动态取色（Dynamic Color）从壁纸生成整套色板
- 圆角刻意大：按钮 999px、卡片 16~28px
- Tonals：主色衍生 5 档深浅（primary container 等）
- FAB、Chip、导航栏风格统一柔和

**复刻要点**

- 配色用 M3 tonal palette：primary / onPrimary / primaryContainer / onPrimaryContainer
- 阴影柔，多靠 elevation tonal 而非黑阴影
- 按钮高度 40px、Chip 圆角 8px、卡片 12~28px
- 参考 Material Theme Builder 直接生成 token

**范例与适用**:Android 12+ 系统 UI、Google 全家桶、Flutter Material 3 组件库。

**即用 Prompt**

```text
Build a page in "Material You (M3)" (Material 3) style. Replicate: 配色用 M3 tonal palette：primary / onPrimary / primaryContainer / onPrimaryContainer; 阴影柔，多靠 elevation tonal 而非黑阴影; 按钮高度 40px、Chip 圆角 8px、卡片 12~28px; 参考 Material Theme Builder 直接生成 token. ### 7. Bento Grid · 便当盒网格
> 年代 2023+　·　关键词:便当 bento 不等高网格

**精髓**:用大小不一的圆角格子拼成模块化布局，像日式便当盒，信息密度高但层次清晰，是当代 Landing 最爱。

**配色 Palette**: `#0b0b0f` `#1c1c24` `#ff5a3c` `#34d399`

**推荐字体**:`Inter / Geist（现代紧凑无衬线）`

**视觉特征**

- CSS Grid 不等高、不等宽 tile 拼接
- 圆角统一（18~28px），间距 12~16px
- 每格承载一个独立卖点/数据/插图
- 常配深色 + 单色高亮 + 大留白

**复刻要点**

- grid-template-columns: repeat(4,1fr); 配 grid-column/grid-row: span
- tile 用 var(--panel) + 1px 边框 + 大圆角
- 图标/数字放大成视觉锚点，文字克制
- hover 可轻微缩放或亮边框

**范例与适用**:Apple iPhone 产品页、Linear、Vercel、Arc 浏览器官网、2023 后大量 AI 产品落地页。

**即用 Prompt**

```text
Build a page in "Bento Grid" (便当盒网格) style. 用大小不一的圆角格子拼成模块化布局，像日式便当盒，信息密度高但层次清晰，是当代 Landing 最爱。 Visual: CSS Grid 不等高、不等宽 tile 拼接; 圆角统一（18~28px），间距 12~16px; 每格承载一个独立卖点/数据/插图; 常配深色 + 单色高亮 + 大留白. Replicate: grid-template-columns: repeat(4,1fr); 配 grid-column/grid-row: span; tile 用 var(--panel) + 1px 边框 + 大圆角; 图标/数字放大成视觉锚点，文字克制; hover 可轻微缩放或亮边框. Palette: #0b0b0f, #1c1c24, #ff5a3c, #34d399. Font: Inter / Geist（现代紧凑无衬线）.

### 8. Papermorphism · 纸张拟态
> 年代 2018+　·　关键词:纸张层叠 stacked paper

**精髓**:用阴影分层和细微旋转模拟真实纸张堆叠，层与层之间有明确前后关系，文档/笔记感强。

**配色 Palette**: `#fdfcf8` `#ffffff` `#e8e4d8` `#2b2b2b`

**推荐字体**:`Lora / Source Serif（衬线带书卷气）`

**视觉特征**

- 每层白卡 + 不同 y 偏移阴影制造堆叠
- 轻微 rotate(-1~2deg) 打破规整
- 纸质米白底 #fdfcf8，非纯白
- 边缘可有 1px 极淡描边

**复刻要点**

- box-shadow: 0 1px 1px rgba(0,0,0,.04), 0 10px 30px rgba(0,0,0,.06)
- 上层卡片 transform: rotate(2deg) translateY(-4px)
- 背景加微噪点纹理（noise）增强纸感
- 适合笔记、文档、看板类产品

**范例与适用**:Notion 卡片视图、Trello、部分博客主题、纸质风格作品集。

**即用 Prompt**

```text
Build a page in "Papermorphism" (纸张拟态) style. 用阴影分层和细微旋转模拟真实纸张堆叠，层与层之间有明确前后关系，文档/笔记感强。 Visual: 每层白卡 + 不同 y 偏移阴影制造堆叠; 轻微 rotate(-1~2deg) 打破规整; 纸质米白底 #fdfcf8，非纯白; 边缘可有 1px 极淡描边. Replicate: box-shadow: 0 1px 1px rgba(0,0,0,.04), 0 10px 30px rgba(0,0,0,.06); 上层卡片 transform: rotate(2deg) translateY(-4px); 背景加微噪点纹理（noise）增强纸感; 适合笔记、文档、看板类产品. ### 9. Skeuomorphism 2.0 · 新拟物 2.0
> 年代 2023+　·　关键词:拟物 物理质感 knob dial

**精髓**:在扁平化基础上重新引入微妙物理暗示：纹理、高光、金属/皮革质感、可旋转旋钮，复古而精致。

**配色 Palette**: `#1a1a1f` `#2a2a32` `#ffb84d` `#d4d4dc`

**推荐字体**:`SF Pro / 自定义 Display（高质感）`

**视觉特征**

- 重新拥抱材质：拉丝金属、皮革、玻璃
- 高光与反射：顶部 linear-gradient + 底部阴影
- 物理交互：旋钮旋转、滑块有阻尼
- 精致但不卡通，偏高级感

**复刻要点**

- 用多层 radial/linear gradient 模拟金属圆柱/球面
- box-shadow 内外结合：顶部 inset 高光 + 底部投影
- 纹理用 CSS pattern 或 SVG overlay，低透明度
- visionOS、部分音频/创意工具在回归此风格

**范例与适用**:Apple visionOS 控件、Logic Pro、部分高端音频 App、复古仪表盘 UI。

**即用 Prompt**

### 20. Glossy 3D / Spline Hero · 3D 主视觉
> 年代 2022+　·　关键词:spline hero 3D主视觉 glossy 旋转 单焦点

**精髓**:单个炫酷的 3D 物体作为 hero 主视觉，可旋转交互，暗背景突出，强焦点、强记忆点，是 Spline 时代的主流。

- 暗背景突出 3D，强焦点
