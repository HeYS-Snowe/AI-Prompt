# 沉浸式 / 3D

> 空间感、深度与立体造型:3D 插画、等距、低多边、粒子、全息等,打破平面营造身临其境。
>
> 共 8 种风格。每种含:精髓 / 配色 / 字体 / 视觉特征 / 复刻要点 / 即用 Prompt,并附配套实践 demo 路径。
> 配色与字体仅供快速参考,完整数据见根目录 `styles.json`(机器可读,AI 可直接引用)。

### 1. Spatial UI · 空间计算 UI
> 年代 2024+　·　关键词:空间计算 visionOS AR 透明

**精髓**:为 AR/VR/空间计算设计：透明悬浮面板、深度层级、注视点交互，UI 漂浮在真实空间中，强调深度与通透。

**配色 Palette**: `#0a0a0f` `#ffffff` `#0a84ff` `#ffd60a`

**推荐字体**:`SF Pro（系统一致，高清晰）`

**视觉特征**

- 半透明悬浮窗，背后环境可见
- 窗口可立体排列、有深度 z 层
- 注视点 + 手势交互，无传统点击
- 高对比文字保证通透下的可读性

**复刻要点**

- 面板 backdrop-filter + 高描边 + 大圆角
- 用 transform: translateZ 模拟深度
- 文字加描边/阴影应对复杂背景
- visionOS 设计规范是标杆

**范例与适用**:Apple Vision Pro / visionOS、Meta Quest Horizon OS、Spatial Web、AR 导航。

**即用 Prompt**

```text
Build a page in "Spatial UI" (空间计算 UI) style. 为 AR/VR/空间计算设计：透明悬浮面板、深度层级、注视点交互，UI 漂浮在真实空间中，强调深度与通透。 Visual: 半透明悬浮窗，背后环境可见; 窗口可立体排列、有深度 z 层; 注视点 + 手势交互，无传统点击; 高对比文字保证通透下的可读性. Replicate: 面板 backdrop-filter + 高描边 + 大圆角; 用 transform: translateZ 模拟深度; 文字加描边/阴影应对复杂背景; visionOS 设计规范是标杆. Palette: #0a0a0f, #ffffff, #0a84ff, #ffd60a. Font: SF Pro（系统一致，高清晰）.
```

### 2. 3D Isometric · 等距 3D
> 年代 常青　·　关键词:等距 isometric 2.5D 轴测

**精髓**:30 度等距投影的 2.5D 插画风格，用平面图形拼出立体场景，清晰、可爱、信息量大，无需真 3D。

**配色 Palette**: `#6c5ce7` `#00cec9` `#fdcb6e` `#dfe6e9`

**推荐字体**:`Poppins / Inter（圆润现代）`

**视觉特征**

- 等距投影（30°/30°）画立方体场景
- 平面色块拼出立体感
- 配色明亮、饱和、统一
- 无透视变形，可读性高

**复刻要点**

- 用 transform: rotate(45deg) skewX/Y 模拟等距面
- 或直接用 isometric SVG 插画
- 三个面用三档明度区分（亮/中/暗）
- 配色锁定 4~6 色统一调色板

**范例与适用**:SaaS 插画（如 Stripe）、游戏地图、信息图表、产品功能图解。

**即用 Prompt**

```text
Build a page in "3D Isometric" (等距 3D) style. 30 度等距投影的 2.5D 插画风格，用平面图形拼出立体场景，清晰、可爱、信息量大，无需真 3D。 Visual: 等距投影（30°/30°）画立方体场景; 平面色块拼出立体感; 配色明亮、饱和、统一; 无透视变形，可读性高. Replicate: 用 transform: rotate(45deg) skewX/Y 模拟等距面; 或直接用 isometric SVG 插画; 三个面用三档明度区分（亮/中/暗）; 配色锁定 4~6 色统一调色板. Palette: #6c5ce7, #00cec9, #fdcb6e, #dfe6e9. Font: Poppins / Inter（圆润现代）.
```

### 3. Clay 3D · 黏土 3D
> 年代 2022+　·　关键词:黏土3d spline soft render

**精髓**:用 Spline/Blender 渲染的柔软黏土质感 3D 元素，圆润、哑光、可爱，是当代网页 3D 主流，亲切无攻击性。

**配色 Palette**: `#ff9a8b` `#a18cd1` `#fbc2eb` `#84fab0`

**推荐字体**:`Clash Display / Outfit（圆润现代展示字）`

**视觉特征**

- 柔软黏土质感（次表面散射 SSS）
- 哑光、圆润、无锐边
- 柔和全局光照
- 配色马卡龙，亲和力强

**复刻要点**

- 用 Spline 制作 clay 材质模型导出
- 材质：粗糙度高、柔光、SSS
- 配色马卡龙系，柔和过渡
- 网页用 Spline viewer 或导出 webm/glb

**范例与适用**:Spline 官网、Linear 插画、部分 AI 产品 hero、潮流品牌 3D IP。

**即用 Prompt**

```text
Build a page in "Clay 3D" (黏土 3D) style. 用 Spline/Blender 渲染的柔软黏土质感 3D 元素，圆润、哑光、可爱，是当代网页 3D 主流，亲切无攻击性。 Visual: 柔软黏土质感（次表面散射 SSS）; 哑光、圆润、无锐边; 柔和全局光照; 配色马卡龙，亲和力强. Replicate: 用 Spline 制作 clay 材质模型导出; 材质：粗糙度高、柔光、SSS; 配色马卡龙系，柔和过渡; 网页用 Spline viewer 或导出 webm/glb. Palette: #ff9a8b, #a18cd1, #fbc2eb, #84fab0. Font: Clash Display / Outfit（圆润现代展示字）.
```

### 4. Glass / Crystal 3D · 玻璃/晶体 3D
> 年代 2023+　·　关键词:玻璃3d 水晶 折射 glassy

**精髓**:高透明玻璃/水晶质感的 3D 渲染，强折射、强高光、内部色散，通透、奢华、未来感，适合 hero 焦点。

**配色 Palette**: `#a0e9ff` `#c9b8ff` `#ffffff` `#5b86ff`

**推荐字体**:`Satoshi / Space Grotesk（现代干净）`

**视觉特征**

- 高透明 + 强折射（IOR 高）
- 内部色散（彩虹边缘）
- 强高光、强环境反射
- 深色背景衬托通透感

**复刻要点**

- Blender/Octane 玻璃材质（transmission 1, roughness 0, IOR 1.5）
- 开启 caustics 焦散，加色散
- 深色环境 + HDRI 反射
- 网页导出 webm/glb，循环旋转

**范例与适用**:Apple 产品 hero（Vision Pro 玻璃）、AI 产品视觉、奢侈品牌 3D、加密项目。

**即用 Prompt**

```text
Build a page in "Glass / Crystal 3D" (玻璃/晶体 3D) style. 高透明玻璃/水晶质感的 3D 渲染，强折射、强高光、内部色散，通透、奢华、未来感，适合 hero 焦点。 Visual: 高透明 + 强折射（IOR 高）; 内部色散（彩虹边缘）; 强高光、强环境反射; 深色背景衬托通透感. Replicate: Blender/Octane 玻璃材质（transmission 1, roughness 0, IOR 1.5）; 开启 caustics 焦散，加色散; 深色环境 + HDRI 反射; 网页导出 webm/glb，循环旋转. Palette: #a0e9ff, #c9b8ff, #ffffff, #5b86ff. Font: Satoshi / Space Grotesk（现代干净）.
```

### 5. Low Poly · 低多边形
> 年代 2010s+　·　关键词:低多边形 lowpoly 几何面

**精髓**:用少量三角面拼出的几何化 3D，保留棱角与色块，复古游戏感、抽象艺术感，轻量且风格化。

**配色 Palette**: `#ff6b6b` `#4ecdc4` `#ffe66d` `#1a535c`

**推荐字体**:`Montserrat / Bebas（硬朗几何）`

**视觉特征**

- 明显的三角面棱角
- 每面纯色，靠明暗区分
- 配色风格化、对比强
- 轻量，适合 web/游戏

**复刻要点**

- 建模时降低面数，保留 flat shading
- 每个面纯色，三角面交界可见
- 配色锁定对比强的调色板
- 可用 Three.js MeshStandardMaterial flatShading

**范例与适用**:独立游戏、抽象 3D 插画、活动海报背景、部分品牌 IP。

**即用 Prompt**

```text
Build a page in "Low Poly" (低多边形) style. 用少量三角面拼出的几何化 3D，保留棱角与色块，复古游戏感、抽象艺术感，轻量且风格化。 Visual: 明显的三角面棱角; 每面纯色，靠明暗区分; 配色风格化、对比强; 轻量，适合 web/游戏. Replicate: 建模时降低面数，保留 flat shading; 每个面纯色，三角面交界可见; 配色锁定对比强的调色板; 可用 Three.js MeshStandardMaterial flatShading. Palette: #ff6b6b, #4ecdc4, #ffe66d, #1a535c. Font: Montserrat / Bebas（硬朗几何）.
```

### 6. Scroll-driven Cinematic · 滚动叙事
> 年代 2020+　·　关键词:滚动叙事 scroll storytelling 视差

**精髓**:滚动驱动的故事化体验：随滚动推进场景变换、镜头运动、内容揭示，像交互式电影，沉浸感极强。

**配色 Palette**: `#0a0a0f` `#ffffff` `#ff5a3c` `#1a1a2e`

**推荐字体**:`Custom display + Inter（叙事感标题）`

**视觉特征**

- 滚动绑定动画（GSAP ScrollTrigger）
- 场景/镜头随滚动变换
- 文字与视觉交错揭示
- 视差、缩放、形变制造纵深

**复刻要点**

- GSAP ScrollTrigger + Lenis 平滑滚动
- 用 pin 锁定章节，滚动驱动 timeline
- 多层视差：translateY 速度不同
- 章节间用大标题 + 揭示动效

**范例与适用**:Apple 产品页、AirPods 介绍页、NASA 任务页、获奖 Awwwards 站点。

**即用 Prompt**

```text
Build a page in "Scroll-driven Cinematic" (滚动叙事) style. 滚动驱动的故事化体验：随滚动推进场景变换、镜头运动、内容揭示，像交互式电影，沉浸感极强。 Visual: 滚动绑定动画（GSAP ScrollTrigger）; 场景/镜头随滚动变换; 文字与视觉交错揭示; 视差、缩放、形变制造纵深. Replicate: GSAP ScrollTrigger + Lenis 平滑滚动; 用 pin 锁定章节，滚动驱动 timeline; 多层视差：translateY 速度不同; 章节间用大标题 + 揭示动效. Palette: #0a0a0f, #ffffff, #ff5a3c, #1a1a2e. Font: Custom display + Inter（叙事感标题）.
```

### 7. Particle Field · 粒子场
> 年代 2020+　·　关键词:粒子 particle canvas three.js

**精髓**:漂浮的光点/星尘/粒子构成动态背景，梦幻、科技、有生命力，常作为 hero 背景，增强氛围。

**配色 Palette**: `#0b0b0f` `#7dd3fc` `#c4b5fd` `#fde047`

**推荐字体**:`Inter / Geist（不抢粒子风头）`

**视觉特征**

- 大量小粒子漂浮（canvas/three.js）
- 鼠标交互：粒子被吸引/排斥
- 配色深底 + 亮色粒子
- 性能可控，粒子数自适应

**复刻要点**

- Three.js Points 或 Canvas 2D 画粒子
- 加鼠标力场（距离反比）
- 粒子用 additive blend 发光
- requestAnimationFrame，粒子数限 200~2000

**范例与适用**:Particle.js 示例、AI 产品 hero、科技公司官网、获奖创意站。

**即用 Prompt**

```text
Build a page in "Particle Field" (粒子场) style. 漂浮的光点/星尘/粒子构成动态背景，梦幻、科技、有生命力，常作为 hero 背景，增强氛围。 Visual: 大量小粒子漂浮（canvas/three.js）; 鼠标交互：粒子被吸引/排斥; 配色深底 + 亮色粒子; 性能可控，粒子数自适应. Replicate: Three.js Points 或 Canvas 2D 画粒子; 加鼠标力场（距离反比）; 粒子用 additive blend 发光; requestAnimationFrame，粒子数限 200~2000. Palette: #0b0b0f, #7dd3fc, #c4b5fd, #fde047. Font: Inter / Geist（不抢粒子风头）.
```

### 8. Modern Gradient Web · 现代渐变 Web
> 年代 2023+　·　关键词:渐变 stripe vercel 现代

**精髓**:Stripe/Vercel 式精致渐变：流动光带、网格背景、柔和渐变文字，干净、专业、有科技感，是当代 SaaS 标配。

**配色 Palette**: `#0a0a0f` `#ffffff` `#5b21b6` `#0ea5e9`

**推荐字体**:`Geist / Inter（现代紧凑，负字距）`

**视觉特征**

- 背景网格 + 流动渐变光带
- 渐变文字（background-clip:text）
- 深色底 + 单色高光
- 精致、克制、有质感

**复刻要点**

- 网格：background-image linear-gradient 网格线
- 光带：径向/锥形渐变 + blur + 缓动位移
- 文字渐变：linear-gradient + -webkit-background-clip:text
- 配色深底，高光用品牌色渐变

**范例与适用**:Stripe、Vercel、Linear、Resend、当下所有顶级 SaaS 落地页。

**即用 Prompt**

```text
Build a page in "Modern Gradient Web" (现代渐变 Web) style. Stripe/Vercel 式精致渐变：流动光带、网格背景、柔和渐变文字，干净、专业、有科技感，是当代 SaaS 标配。 Visual: 背景网格 + 流动渐变光带; 渐变文字（background-clip:text）; 深色底 + 单色高光; 精致、克制、有质感. Replicate: 网格：background-image linear-gradient 网格线; 光带：径向/锥形渐变 + blur + 缓动位移; 文字渐变：linear-gradient + -webkit-background-clip:text; 配色深底，高光用品牌色渐变. Palette: #0a0a0f, #ffffff, #5b21b6, #0ea5e9. Font: Geist / Inter（现代紧凑，负字距）.
```
