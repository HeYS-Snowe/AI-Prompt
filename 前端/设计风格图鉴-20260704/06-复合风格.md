### 1. Doodle Brutalism · 涂鸦工业风
> 年代 2022+　·　关键词:涂鸦工业风 doodle brutalism neo-brutal 手绘 新粗野 你画我猜

**精髓**:Neo-Brutalism 的硬边骨架 + 涂鸦手绘的纸感表面：粗黑实线、硬实心阴影、饱和撞色，再覆一层素描纸纹理与手写体，活泼俏皮又有结构。Gumroad、你画我猜类游戏的标准配方。

**配色 Palette**: `#ffd93d` `#ff6b6b` `#4ecdc4` `#1a1a1a`

**推荐字体**:`ZCOOL KuaiLe / Patrick Hand（手写体）配 Noto Sans SC 正文`

**视觉特征**

- 骨架：4px 墨黑实线边框 + 6px 硬实心偏移阴影（无模糊）
- 表面：素描纸底 #FBF7EE + 28px 网格纹理模拟方格本
- 配色高饱和撞色：暖黄/番茄红/薄荷绿/靛蓝，每块一个亮色
- 手写体标题 + 漂浮涂鸦 SVG 图标，hover 上浮按下归零

**复刻要点**

- 边框 border:4px solid #1a1a1a；阴影 box-shadow:6px 6px 0 #1a1a1a
- 纸纹：body background-image 画 28px 网格 + 噪点
- 字体 display 用 ZCOOL KuaiLe，正文 Noto Sans SC
- hover transform:translate(-.5rem,-.5rem) shadow:10px 10px 0；active 归零

**范例与适用**:你画我猜类游戏（《你画我猜》）、Gumroad、Notion 部分插画、独立开发者产品、儿童/教育向 SaaS。

**即用 Prompt**


### 2. Linear Aurora Bento · Linear 极光便当

**推荐字体**:`Inter / Geist（紧凑负字距 -0.02~-0.04em）`

### 3. Glassmorphism + Clay · 毛玻璃黏土
> 年代 2022+　·　关键词:毛玻璃 黏土 glass clay 柔和现代 saas

**精髓**:玻璃拟态的通透面板 + 黏土拟态的圆润立体：半透明毛玻璃卡片漂浮在彩色渐变上，内部带黏土感的胖圆角与内阴影。柔和、现代、亲和，教育与协作产品爱用。

**配色 Palette**: `#a78bfa` `#f0abfc` `#7dd3fc` `#ffffff`

**推荐字体**:`Quicksand / Nunito（圆润几何）`

**视觉特征**

- 毛玻璃：backdrop-filter blur(16-20px) + 1px 白描边
- 黏土：大圆角 24-32px + 内阴影高光 + 柔和外阴影
- 背景彩色渐变（紫粉蓝），玻璃透出
- 配色马卡龙，亲和无攻击性

**复刻要点**

- 卡片 backdrop-filter:blur(20px) + rgba 填充 + 圆角 28px
- box-shadow: inset 0 6px 12px rgba(255,255,255,.5), 0 12px 24px rgba(0,0,0,.12)
- 背景 linear-gradient 多彩供玻璃透出
- 文字白/深色，配文字阴影保证可读

**范例与适用**:Spline、教育/儿童产品、协作 SaaS、设计工具引导页。
