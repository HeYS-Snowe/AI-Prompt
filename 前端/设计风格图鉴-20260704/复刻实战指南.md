# 复刻实战指南

> 把「看到好看」变成「复刻得出来」的可操作方法。配合各分册的「即用 Prompt」使用。
> 适用于人手动复刻,也适用于驱动 AI(Vibe Coding)。

---

## 一、复刻三步法

### 第一步:识别风格
看到喜欢的页面,按以下顺序判断它属于哪个流派(对应分册):

1. **看质感**:毛玻璃 → 玻璃拟态(01);硬实心阴影 → 新野性(02);胖圆内阴影 → 黏土(01);金属反光 → 金属拟态(01)
2. **看背景**:深色霓虹 → 赛博(02);粉紫渐变 → 蒸汽波(02);米白大留白 → 极简(02);严格网格 → 瑞士(02)
3. **看布局**:不等高圆角格子 → 便当盒(01);多栏衬线 → 杂志(02);透视网格 → 合成波(02);全屏 3D → 沉浸式(03)
4. **看平台**:触屏 Tab Bar → 移动端(04);密集表格 → 桌面后台(05);命令面板 → IDE(05)

### 第二步:拆解五要素
打开该风格所在分册,抄下它的:

- **配色** — `palette` 字段,hex 值
- **字体** — `type` 字段
- **视觉特征** — `features` 列表(它长什么样)
- **复刻要点** — `replicate` 列表(具体 CSS / 参数 / 怎么做)

或直接读 `styles.json` 中该风格的对象,字段更全。

### 第三步:驱动 AI 生成
把该风格的「即用 Prompt」粘给 Claude Code / Cursor / CodeX;或把 `styles.json` 中该风格对象整段喂给 AI,让其严格按数据复刻。

## 二、Prompt 模板

### 模板 A:单风格复刻
```
用 [React + Tailwind CSS] 实现 [风格名] 风格的页面。

[粘贴该风格分册里的「即用 Prompt」]

要求:响应式、组件化、带悬停微交互、不使用 emoji 图标(改用 lucide-react)、配色严格按 palette。
```

### 模板 B:复合风格(直接用 06 分册)
`06-复合风格.md` 里的 8 个复合风格本身就是经过验证的混搭 Prompt,直接复制其「即用 Prompt」即可,无需自己拼。

### 模板 C:精准数据驱动(最严谨)
```
读取 styles.json 中 id 为 "<风格id>" 的对象,严格按其 features / replicate / palette / type 字段,
用 [技术栈] 实现一个落地页。不得擅自更改配色与字体。
```

## 三、混搭黄金组合

`06-复合风格.md` 收录 8 种实战混搭,均为当代产品验证过的配方:

| 组合 | 分册条目 | 配方 | 典型场景 |
|---|---|---|---|
| Linear 极光便当 | 06-2 | Linear 暗色克制 + 极光光晕 + Bento 网格 | AI / SaaS 落地页(Linear、Cursor、Vercel) |
| 毛玻璃黏土 | 06-3 | 毛玻璃通透面板 + 黏土圆润立体 | 教育 / 协作 / 儿童产品 |
| 赛博战术风 | 06-5 | 赛博霓虹暗底 + HUD 战术面板 | 游戏 / 区块链 / 电竞 |
| 便当粗野 | 06-8 | Bento 网格 + Neo-Brutalism 硬边撞色 | 独立 SaaS / 个人项目 |
| 涂鸦工业风 | 06-1 | 新野性骨架 + 涂鸦手绘纸感 | 教育 / 独立开发者 / 你画我猜类 |
| 杂志沉浸 | 06-4 | 杂志排版 + 全屏滚动叙事 | 高端品牌故事 / 时尚媒体 |
| 治愈有机 | 06-6 | 治愈留白 + 有机曲线 | 健康 / 母婴 / 冥想 |
| 开发者网格 | 06-7 | 黑白极简 + 网格背景 + 等宽 | 开发者工具 / 开源项目 |

**自定义混搭原则**:主风格(定基调)+ 副风格(加特色),不超过两种主风格,否则失去辨识度。

## 四、避坑提醒

1. **玻璃 / 液态玻璃** — `backdrop-filter` 在低端设备耗性能,长列表 / 表格慎用,仅用于浮层、导航、弹窗
2. **新拟态** — 对比度低,可访问性差,生产环境的表单与高密度信息慎用
3. **新野性 / 便当粗野** — 硬实心阴影在密集表格里会显脏,适合落地页不适合后台
4. **极繁 / 孟菲斯** — 元素密集易乱,必须保留一个明确的视觉中心
5. **3D / 粒子 / 全息** — 资产体积大,务必懒加载,避免拖慢首屏
6. **赛博 / 蒸汽波** — 霓虹高饱和长时间观看伤眼,正文区保持足够可读对比度
7. **风格服务内容** — 先定产品定位与目标用户,再选风格,不为风格而风格
8. **混搭克制** — 主副风格各一,总元素不超过两套视觉语言,避免杂乱

## 五、与 .prompt 其他库配合

复刻一个真实产品时,建议按以下顺序调用 .prompt 各库:

1. **`.prompt/设计/`** — 先读设计原则(苹果 HIG、Rams 十原则、尼尔森启发式),定基调与可用性底线
2. **本图鉴** — 选定风格(或复合风格),取配色 / 字体 / 复刻要点
3. **`.prompt/前端/`(其他文件)** — 查实现规范(如 Flutter 亚克力 / 液态玻璃的具体落地代码)
4. **`.prompt/awesome-design-md-main/`** — 参考真实品牌的设计系统 DESIGN.md,对齐工业级标准
