# 桌面软件

>
> 共 10 种风格。每种含:精髓 / 配色 / 字体 / 视觉特征 / 复刻要点 / 即用 Prompt,并附配套实践 demo 路径。

### 1. macOS / Aqua Native · macOS 原生
> 年代 常青　·　关键词:macOS aqua 苹果 系统原生

**精髓**:macOS 原生风格：毛玻璃工具栏、红黄绿交通灯、侧边栏 + 主区、精致系统字体，克制、优雅、高一致。

**配色 Palette**: `#e6e6e6` `#ffffff` `#1d1d1f` `#0a84ff`

**推荐字体**:`SF Pro Text（系统字体）`

**视觉特征**

- 顶部毛玻璃工具栏 + 交通灯按钮
- 侧边栏（半透明）+ 主内容区
- 系统级圆角与阴影
- 字体 SF Pro，字重克制

**复刻要点**

- 工具栏 blur(20px) + vibrancy 半透明
- 交通灯 #ff5f57/#febc2e/#28c840
- 窗口圆角 10px + 大投影
- 侧边栏 #e6e6e6 半透明，主区白

**范例与适用**:macOS 系统应用（访达、邮件）、Apple 自家 Mac App、大量原生 Mac 软件。

**即用 Prompt**

```text
Build a page in "macOS / Aqua Native" (macOS 原生) style. macOS 原生风格：毛玻璃工具栏、红黄绿交通灯、侧边栏 + 主区、精致系统字体，克制、优雅、高一致。 Visual: 顶部毛玻璃工具栏 + 交通灯按钮; 侧边栏（半透明）+ 主内容区; 系统级圆角与阴影; 字体 SF Pro，字重克制. Replicate: 工具栏 blur(20px) + vibrancy 半透明; 交通灯 #ff5f57/#febc2e/#28c840; 窗口圆角 10px + 大投影; 侧边栏 #e6e6e6 半透明，主区白. Palette: #e6e6e6, #ffffff, #1d1d1f, #0a84ff. Font: SF Pro Text（系统字体）.
```

### 2. Windows 11 Mica/Acrylic · Windows 11 原生

- Mica 云母：窗口背景取桌面壁纸色调
- 圆角窗口（8px）+ 居中任务栏
- Acrylic 用于菜单/面板半透明
- 强调色 #005fb8 系统蓝

- 窗口圆角 8px，Mica 用 wallpaper-tinted 纯色
- 菜单/弹层 Acrylic：blur(30px) + 着色
- 强调色用系统 accent，圆角统一 4~8px

**范例与适用**:Windows 11 系统应用、Microsoft 365、Edge、PowerToys。

### 10. Sidebar Matte · 磨砂侧栏
> 年代 macOS Ventura+　·　关键词:磨砂侧栏 sidebar matte vibrancy macos 半透明

**精髓**:macOS Ventura 式磨砂侧边栏，半透明模糊跟随后台颜色变化（vibrancy 活力模糊），连贯、通透、系统感强。

**配色 Palette**: `#e8e8ec` `#1a1a2e` `#0a84ff` `#ffffff`

**推荐字体**:`SF Pro Text（系统字体）`

**视觉特征**

- 侧栏半透明 + backdrop-filter blur
- 跟随壁纸/后台颜色变化（vibrancy）
- 与主区分明（细线/圆角）
- 系统级连贯感

**复刻要点**

- 侧栏 backdrop-filter: blur(30px) saturate(180%)
- 背景半透明 rgba，透出桌面色
- 侧栏与主区用圆角分离（macOS 风格）
- 选中项用系统强调色

**范例与适用**:macOS Ventura/Sonoma 原生应用、访达、邮件、备忘录、部分跨平台 App。

**即用 Prompt**

