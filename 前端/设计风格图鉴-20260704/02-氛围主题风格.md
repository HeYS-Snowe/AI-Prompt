### 1. Brutalism · 野性主义
> 年代 2014+　·　关键词:野性 粗犷 raw monospace

**精髓**:反精致的叛逆：系统字体、裸露结构、大字号、强对比、无圆角无阴影，像 90 年代裸 HTML 又刻意为之。

**配色 Palette**: `#ffffff` `#000000` `#ff4500` `#ffff00`

**推荐字体**:`Courier New / system-ui mono（系统等宽，拒绝美化）`

**视觉特征**

- 纯黑纯白高对比，偶尔荧光色点缀
- 无圆角、无渐变、无阴影，边框粗实线
- 超大字号标题，正文密集
- 故意「丑」、信息直给、反装饰

**复刻要点**

- font-family: "Courier New", monospace; color:#000; background:#fff
- border: 3px solid #000; border-radius:0
- 链接带下划线，悬停反色（background:#000;color:#fff）
- HTML 元素直接裸用，少 CSS 包装

**范例与适用**:Bloomberg、Yale School of Art、Are.na、部分独立博客与设计师作品集。

**即用 Prompt**

```text
Build a page in "Brutalism" (野性主义) style. 反精致的叛逆：系统字体、裸露结构、大字号、强对比、无圆角无阴影，像 90 年代裸 HTML 又刻意为之。 Visual: 纯黑纯白高对比，偶尔荧光色点缀; 无圆角、无渐变、无阴影，边框粗实线; 超大字号标题，正文密集; 故意「丑」、信息直给、反装饰. Replicate: font-family: "Courier New", monospace; color:#000; background:#fff; border: 3px solid #000; border-radius:0; 链接带下划线，悬停反色（background:#000;color:#fff）; HTML 元素直接裸用，少 CSS 包装. Palette: #ffffff, #000000, #ff4500, #ffff00. Font: Courier New / system-ui mono（系统等宽，拒绝美化）.
```

### 2. Neo-Brutalism · 新野性主义
> 年代 2021+　·　关键词:新野性 粗黑边 亮色 偏移阴影

**精髓**:野性主义的可爱进化版：粗黑实线边框 + 饱和亮色 + 硬投影偏移，活泼、醒目、强交互感，是 2022 后流行风。

**配色 Palette**: `#ffe156` `#ff6b9d` `#4d96ff` `#1a1a1a`

**推荐字体**:`Space Grotesk / Archivo（粗壮几何）`

**视觉特征**

- 边框统一 2~4px 纯黑实线 #000
- 硬投影 box-shadow: 4px 4px 0 #000（无模糊）
- 底色高饱和：黄、粉、蓝、绿
- 圆角 0~12px，按钮按下偏移归零

**复刻要点**

- box-shadow: 6px 6px 0 #1a1a1a; border: 3px solid #1a1a1a
- hover：transform: translate(-2px,-2px); shadow: 8px 8px 0
- 配色块状对比，每块一个亮色
- 字体用粗黑几何无衬线，权重 700+

**范例与适用**:Gumroad、Linear 早期、Framer 模板、大量 indie SaaS 与 Web3 产品。

**即用 Prompt**

```text
Build a page in "Neo-Brutalism" (新野性主义) style. 野性主义的可爱进化版：粗黑实线边框 + 饱和亮色 + 硬投影偏移，活泼、醒目、强交互感，是 2022 后流行风。 Visual: 边框统一 2~4px 纯黑实线 #000; 硬投影 box-shadow: 4px 4px 0 #000（无模糊）; 底色高饱和：黄、粉、蓝、绿; 圆角 0~12px，按钮按下偏移归零. Replicate: box-shadow: 6px 6px 0 #1a1a1a; border: 3px solid #1a1a1a; hover：transform: translate(-2px,-2px); shadow: 8px 8px 0; 配色块状对比，每块一个亮色; 字体用粗黑几何无衬线，权重 700+. Palette: #ffe156, #ff6b9d, #4d96ff, #1a1a1a. Font: Space Grotesk / Archivo（粗壮几何）.
```

### 3. Minimalism · 极简主义
> 年代 常青　·　关键词:极简 留白 less is more

**精髓**:大量留白、极少元素、呼吸感强。用克制换取高级感，每个元素都有存在的理由，less is more。

**配色 Palette**: `#ffffff` `#fafafa` `#111111` `#c0c0c0`

**推荐字体**:`Inter / Helvetica Now（中性无衬线）`

**视觉特征**

- 超大留白，元素稀疏
- 配色克制：黑白灰 + 极少强调色
- 字号层级靠字重和灰度而非颜色
- 网格严格对齐，一丝不苟

**复刻要点**

- padding/margin 翻倍，敢于留白
- 配色限制在 3 色内：白、黑、一灰
- 标题用细字重（300~500），大字号
- 动效极轻：opacity / translateY 200ms

**范例与适用**:Apple、MUJI 官网、Linear、Vercel、大多数高端品牌。

**即用 Prompt**

```text
Build a page in "Minimalism" (极简主义) style. 大量留白、极少元素、呼吸感强。用克制换取高级感，每个元素都有存在的理由，less is more。 Visual: 超大留白，元素稀疏; 配色克制：黑白灰 + 极少强调色; 字号层级靠字重和灰度而非颜色; 网格严格对齐，一丝不苟. Replicate: padding/margin 翻倍，敢于留白; 配色限制在 3 色内：白、黑、一灰; 标题用细字重（300~500），大字号; 动效极轻：opacity / translateY 200ms. Palette: #ffffff, #fafafa, #111111, #c0c0c0. Font: Inter / Helvetica Now（中性无衬线）.
```

### 4. Maximalism · 极繁主义
> 年代 2020+　·　关键词:极繁 密集 more is more 拼贴

**精髓**:与极简对立：丰富装饰、多层叠加、信息密集、色彩饱和，more is more，热闹、 expressive、视觉爆炸。

**配色 Palette**: `#ff006e` `#fb5607` `#ffbe0b` `#3a86ff` `#8338ec`

**推荐字体**:`Bricolage / Anton（多变展示字体）`

**视觉特征**

- 元素堆叠、旋转、错位
- 多色块、多图案、多纹理并置
- 文字与图形交织，不留空白
- 动效密集，常带粒子和流动

**复刻要点**

- 允许重叠：z-index + transform: rotate
- 配色 5~7 色高饱和，冷暖混搭
- 背景放图案/贴纸/SVG 装饰填满
- 每寸空间都有内容，但需一个视觉中心

**范例与适用**:部分创意机构官网、乐队/音乐节海报、Z 世代潮流品牌、Web3 项目。

**即用 Prompt**

```text
Build a page in "Maximalism" (极繁主义) style. 与极简对立：丰富装饰、多层叠加、信息密集、色彩饱和，more is more，热闹、 expressive、视觉爆炸。 Visual: 元素堆叠、旋转、错位; 多色块、多图案、多纹理并置; 文字与图形交织，不留空白; 动效密集，常带粒子和流动. ### 5. Swiss Style · 瑞士国际主义
```
> 年代 1950s　·　关键词:瑞士 网格 helvetica 不对称

**精髓**:严格网格、无衬线字体、不对称布局、客观摄影。理性、秩序、信息层级清晰，是现代平面设计之祖。

**配色 Palette**: `#ffffff` `#111111` `#d6001c` `#f5f5f5`

**推荐字体**:`Helvetica / Inter（经典无衬线）`

**视觉特征**

- 12 栏严格网格，一切对齐
- 无衬线、左对齐、字距紧
- 不对称构图，留白也是设计
- 红色作为唯一强调，黑白为主

**复刻要点**

- CSS Grid 12 列，元素严格吸附
- font-size 阶梯清晰（8/12/24/48），字重分级
- 大量左对齐文本块，标题靠字号而非颜色
- 配色：#fff / #111 / 一个 #d6001c

**范例与适用**:Apple 早期设计、众多博物馆/美术馆官网、瑞士联邦铁路、经典海报传统。

**即用 Prompt**

```text
Build a page in "Swiss Style" (瑞士国际主义) style. 严格网格、无衬线字体、不对称布局、客观摄影。理性、秩序、信息层级清晰，是现代平面设计之祖。 Visual: 12 栏严格网格，一切对齐; 无衬线、左对齐、字距紧; 不对称构图，留白也是设计; 红色作为唯一强调，黑白为主. Replicate: CSS Grid 12 列，元素严格吸附; font-size 阶梯清晰（8/12/24/48），字重分级; 大量左对齐文本块，标题靠字号而非颜色; 配色：#fff / #111 / 一个 #d6001c. Palette: #ffffff, #111111, #d6001c, #f5f5f5. Font: Helvetica / Inter（经典无衬线）.
```

### 6. Bauhaus · 包豪斯
> 年代 1919　·　关键词:包豪斯 几何 三原色 功能主义

**精髓**:几何图形（圆、方、三角）+ 三原色（红黄蓝）+ 功能主义。形式追随功能，影响整个现代设计。

**配色 Palette**: `#e63946` `#f4d35e` `#1d3557` `#ffffff`

**推荐字体**:`Futura / Universal（几何无衬线）`

**视觉特征**

- 基本几何：圆=黄、方=红、三角=蓝
- 构图基于几何叠加与分割
- 无装饰，纯色块
- 字体几何化、字距紧

**复刻要点**

- 用 SVG/CSS 画大圆、大方、三角叠加
- 配色锁三原色 + 黑白
- 字体用 Futura / Poppins 几何体
- 排版追求平衡而非对称

**范例与适用**:包豪斯学校档案、部分设计博物馆、复古几何风品牌、海报传统。

**即用 Prompt**

```text
Build a page in "Bauhaus" (包豪斯) style. 几何图形（圆、方、三角）+ 三原色（红黄蓝）+ 功能主义。形式追随功能，影响整个现代设计。 Visual: 基本几何：圆=黄、方=红、三角=蓝; 构图基于几何叠加与分割; 无装饰，纯色块; 字体几何化、字距紧. Replicate: 用 SVG/CSS 画大圆、大方、三角叠加; 配色锁三原色 + 黑白; 字体用 Futura / Poppins 几何体; 排版追求平衡而非对称. Palette: #e63946, #f4d35e, #1d3557, #ffffff. Font: Futura / Universal（几何无衬线）.
```

### 7. Memphis Style · 孟菲斯
> 年代 1980s　·　关键词:孟菲斯 波普 几何图案 波浪线

**精髓**:80 年代反主流：波普色彩、几何图案（波浪线、锯齿、圆点）、活泼俏皮、打破规则，复古而欢快。

**配色 Palette**: `#ff6b9d` `#4ecdc4` `#ffe66d` `#1a1a1a`

**推荐字体**:`Rubik / Raleway（几何圆润）`

**视觉特征**

- 背景布满波点/锯齿/波浪等几何图案
- 饱和撞色：粉、青、黄、黑
- 图形随手摆放，不规则但和谐
- 俏皮、童趣、反严肃

**复刻要点**

- SVG pattern 画波浪线、波点、锯齿做背景
- 配色撞色，色块边界清晰
- 元素旋转散落，打破网格
- 字体圆润几何，带圆润感

**范例与适用**:80 年代孟菲斯设计集团、复古服装品牌、部分潮流电商、拼贴海报。

**即用 Prompt**

```text
Build a page in "Memphis Style" (孟菲斯) style. 80 年代反主流：波普色彩、几何图案（波浪线、锯齿、圆点）、活泼俏皮、打破规则，复古而欢快。 Visual: 背景布满波点/锯齿/波浪等几何图案; 饱和撞色：粉、青、黄、黑; 图形随手摆放，不规则但和谐; 俏皮、童趣、反严肃. ### 8. Editorial · 杂志编辑风
```
> 年代 常青　·　关键词:杂志 大标题 多栏 图文混排

**精髓**:借鉴纸质杂志排版：大标题、多栏布局、图文混排、首字下沉、精致的行距与字距，阅读体验至上。

**配色 Palette**: `#fcf9f4` `#1a1a1a` `#c1272d` `#8a8a8a`

**推荐字体**:`Playfair Display / Tiempos（衬线大标题）`

**视觉特征**

- 大号衬线标题，强对比
- 正文多栏（2~3 栏）布局
- 首字下沉（drop cap）、引文样式
- 大量留白 + 精致图注

**复刻要点**

- 标题用衬线 display 字体，字号 40~80px
- 正文 column-count: 2/3，行高 1.7
- 首字下沉：first-letter 放大 4~5 倍
- 配色米白底 + 深墨文字 + 一抹红

**范例与适用**:Medium、The New York Times、Apple Newsroom、高端品牌故事页、独立杂志站。

**即用 Prompt**

```text
Build a page in "Editorial" (杂志编辑风) style. 借鉴纸质杂志排版：大标题、多栏布局、图文混排、首字下沉、精致的行距与字距，阅读体验至上。 Visual: 大号衬线标题，强对比; 正文多栏（2~3 栏）布局; 首字下沉（drop cap）、引文样式; 大量留白 + 精致图注. ### 10. Frutiger Aero · 枫木水族风
```
> 年代 2004~2013　·　关键词:水族 glossy 自然 蓝绿 清透

**精髓**:2000s 中期 glossy 自然风：清透蓝绿、水滴、气泡、绿叶、镜面反光，干净乐观的科技自然感，近年强烈回潮。

**配色 Palette**: `#3fb950` `#00a8e8` `#a8e6cf` `#ffffff`

**推荐字体**:`Frutiger / Segoe UI（清透圆润无衬线）`

**视觉特征**

- 清透的蓝绿渐变 + 镜面高光
- 水滴、气泡、水波、绿叶等自然元素
- 玻璃质感按钮带强烈光泽
- 明亮、干净、乐观的氛围

**复刻要点**

- background: linear-gradient 清透蓝绿，配白色高光
- 按钮加 inset 顶部白色高光（gloss）
- 点缀水滴/叶子 SVG 元素
- 字体 Frutiger / Segoe UI 圆润清透

**范例与适用**:Windows Vista/Aero、早期 Apple Aqua、当下回潮的 Windows 11 部分壁纸风、Y2K 后续复兴。
