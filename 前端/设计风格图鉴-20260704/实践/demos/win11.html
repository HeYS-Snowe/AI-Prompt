视觉特征 / 如何复刻

视觉特征

  • Mica 云母：窗口背景取桌面壁纸色调
  • 圆角窗口（8px）+ 居中任务栏
  • Acrylic 用于菜单/面板半透明
  • 强调色 #005fb8 系统蓝

如何复刻

  • 窗口圆角 8px，Mica 用 wallpaper-tinted 纯色
  • 菜单/弹层 Acrylic：blur(30px) + 着色
  • 强调色用系统 accent，圆角统一 4~8px
  • 字体 Segoe UI Variable

范例与适用

Windows 11 系统应用、Microsoft 365、Edge、PowerToys。
