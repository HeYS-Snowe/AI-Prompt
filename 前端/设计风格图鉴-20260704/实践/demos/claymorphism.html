视觉特征 / 如何复刻

视觉特征

  • 圆角极大（24~40px），造型「鼓鼓的」
  • 内阴影 inset 偏移制造顶部高光，外阴影柔和
  • 饱和但不刺眼的马卡龙色
  • 按钮常有「悬浮感」，按下时阴影收缩

如何复刻

  • box-shadow: inset 0 -8px 16px rgba(0,0,0,.12), inset 0 6px 12px rgba(255,255,255,.6), 0 12px 24px rgba(0,0,0,.12)
  • 半径统一偏大，深色基底配浅色高光
  • 适合玩具/儿童/创意产品，严肃后台慎用

范例与适用

Spline 首页插画风组件、部分 Figma 插件、儿童教育 App。
