视觉特征 / 如何复刻

视觉特征

  • 背景必须接近组件色，否则浮雕消失
  • 凸起：box-shadow 同时给 -6,-6,12 #fff 与 6,6,12 rgba(0,0,0,.12)
  • 凹陷：改用 inset 阴影
  • 圆角偏大（14~20px），交互常为「按下变凹陷」

如何复刻

  • 核心：亮阴影 #ffffff + 暗阴影 rgba(163,177,198,.6)
  • 配色限单色系，靠阴影而非颜色区分层级
  • 缺点：可访问性差，按钮与背景对比度低，勿用于需高对比的表单

范例与适用

UI8 Soft UI Dashboard、Alexander Plyuto 原型、部分智能硬件控制面板。

即用 Prompt

Build a page in "Neumorphism" (新拟态 / Soft UI) style. 背景与组件同色，用「亮+暗」双向柔光阴影制造凸起或凹陷，像在软橡皮上压出来的物理按键。 Visual: 背景必须接近组件色，否则浮雕消失; 凸起：box-shadow 同时给 -6,-6,12 #fff 与 6,6,12 rgba(0,0,0,.12); 凹陷：改用 inset 阴影; 圆角偏大（14~20px），交互常为「按下变凹陷」. Palette: #e0e5ec, #9fa6b8, #4a4f5c, #5a7bff. Font: Quicksand / Nunito（圆润几何无衬线）.
