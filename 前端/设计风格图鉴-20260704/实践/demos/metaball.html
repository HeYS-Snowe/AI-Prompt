视觉特征 / 如何复刻

视觉特征

  • 多个圆形/水滴通过 blur + contrast 融合（gooey）
  • 流动渐变填充
  • 有机变形动画
  • 深色底衬托流体质感

如何复刻

  • filter: blur(16px) contrast(20) 实现 gooey 融合
  • 水滴用 border-radius: 50% + 不同色
  • background: 流动渐变
  • SVG gooey filter 或 CSS contrast 技巧
