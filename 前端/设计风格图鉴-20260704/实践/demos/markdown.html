风格速览

Notion 式块编辑工作区：左侧目录 + 中间文档 + 右侧属性，干净、聚焦内容、块可拖拽，是知识管理主流。

视觉特征 / 如何复刻

视觉特征

  • 左目录树 + 中文档 + 右属性
  • 块（block）为单元，可拖拽重组
  • 大量留白，聚焦内容
  • 克制配色，强调内容层级

如何复刻

  • 三栏布局：sidebar / editor / properties
  • 内容用块（段落/标题/列表/代码）
  • 配色 #fff/#f7f7f5/#37352f 极淡
  • hover 显示块手柄（⋮⋮）可拖拽

范例与适用

Notion、Obsidian、Craft、Logseq、各类知识库/文档工具。
