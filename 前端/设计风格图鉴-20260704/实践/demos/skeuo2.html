视觉特征 / 如何复刻

视觉特征

  • 重新拥抱材质：拉丝金属、皮革、玻璃
  • 高光与反射：顶部 linear-gradient + 底部阴影
  • 物理交互：旋钮旋转、滑块有阻尼
  • 精致但不卡通，偏高级感

如何复刻

  • 用多层 radial/linear gradient 模拟金属圆柱/球面
  • box-shadow 内外结合：顶部 inset 高光 + 底部投影
  • 纹理用 CSS pattern 或 SVG overlay，低透明度
  • visionOS、部分音频/创意工具在回归此风格

范例与适用

Apple visionOS 控件、Logic Pro、部分高端音频 App、复古仪表盘 UI。
