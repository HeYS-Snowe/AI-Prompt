视觉特征 / 如何复刻

视觉特征

  • 边框统一 2~4px 纯黑实线 #000
  • 硬投影 box-shadow: 4px 4px 0 #000（无模糊）
  • 底色高饱和：黄、粉、蓝、绿
  • 圆角 0~12px，按钮按下偏移归零

如何复刻

  • box-shadow: 6px 6px 0 #1a1a1a; border: 3px solid #1a1a1a
  • hover：transform: translate(-2px,-2px); shadow: 8px 8px 0
  • 配色块状对比，每块一个亮色
  • 字体用粗黑几何无衬线，权重 700+

范例与适用

Gumroad、Linear 早期、Framer 模板、大量 indie SaaS 与 Web3 产品。
