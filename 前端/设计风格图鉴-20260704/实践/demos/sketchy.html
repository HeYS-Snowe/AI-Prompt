视觉特征 / 如何复刻

视觉特征

  • 手绘 SVG 边框（rough.js 或手画 path）
  • 字体手写体，略歪斜
  • 配色米白纸 + 手绘彩
  • 元素随手摆放，不强对齐

如何复刻

  • 用 rough.js 生成手绘形状，或 SVG path 模拟
  • 字体 Caveat / Patrick Hand
  • 背景米白 #fdfaf3 + 极淡横线（笔记本格）
  • 允许 rotate(±2deg) 打破规整

范例与适用

Excalidraw、手绘风教程网站、设计师作品集、教育类产品。
