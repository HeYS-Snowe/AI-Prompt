视觉特征 / 如何复刻

视觉特征

  • 图形按像素网格（image-rendering: pixelated）
  • 限色 8~16 色调色板
  • 像素字体，字号整数
  • 硬边、无抗锯齿

如何复刻

  • img { image-rendering: pixelated } 保留锯齿
  • 字体 "Press Start 2P" 像素体
  • 配色用限定调色板（如 sweetie16）
  • 元素吸附像素网格对齐

范例与适用

《星露谷物语》《蔚蓝》UI、复古游戏、潮流品牌像素 IP、NFT 像素项目。
