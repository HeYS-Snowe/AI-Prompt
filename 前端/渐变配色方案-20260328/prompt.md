# 渐变与配色方案

> 适用平台：Flutter / 移动端应用
> 核心原则：高级、克制、多样化

---

## 严禁使用的配色

- **禁止** Tailwind 默认紫色到蓝紫色对角渐变配色（`#7C3AED → #2563EB` 等类似色系）
- 此类配色已过时 5 年，视觉上显得低级和陈旧
- 不使用饱和度过高的纯色渐变

## 渐变效果使用规范

### 渐变类型总览

渐变不仅仅是全区域对角渐变，应根据场景灵活选择：

```
1. 全区域渐变          2. 半区域渐变          3. 多色渐变
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ ████████████ │     │              │     │ ████  ██████ │
│ ████████████ │     │              │     │ ████  ██████ │
│ ████████████ │     │ ████████████ │     │ ████████████ │
│ ████████████ │     │ ████████████ │     │ ████████████ │
└──────────────┘     └──────────────┘     └──────────────┘
渐变铺满整个元素      渐变只覆盖下半部分    多个渐变叠加

4. 边角点缀渐变       5. 径向渐变           6. 线性渐变(非对角)
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│██            │     │    ░░░░░     │     │██████████████│
│░░            │     │  ░░░░░░░░   │     │              │
│              │     │ ░░░░░░░░░░░ │     │              │
│              │     │  ░░░░░░░░   │     │              │
└──────────────┘     └──────────────┘     └──────────────┘
仅边角装饰           从中心向外扩散        水平/垂直方向
```

### 各类型适用场景

| 渐变类型        | 适用场景          | 示例            |
| ----------- | ------------- | ------------- |
| 全区域渐变       | 大背景、横幅、Banner | 页面主背景用深色渐变    |
| 半区域渐变       | 卡片底部、头部区域     | 列表头部底部渐变到透明   |
| 多色渐变        | 高级按钮、装饰条、标签   | 按钮内叠加 2-3 种渐变 |
| 边角点缀渐变      | 卡片角落光晕、头像边框   | 卡片右上角微妙光晕     |
| 径向渐变        | 聚光灯效果、焦点区域    | 搜索框聚焦时的光晕     |
| 线性渐变（水平/垂直） | 进度条、分割线装饰     | 细长进度条水平渐变     |

### Flutter 渐变实现

```dart
// 全区域对角渐变
LinearGradient(
  begin: Alignment.topLeft,
  end: Alignment.bottomRight,
  colors: [Color(0xFF1A2F23), Color(0xFF2D4A3E)],
)

// 半区域渐变（使用 stops 控制范围）
LinearGradient(
  begin: Alignment.topCenter,
  end: Alignment.bottomCenter,
  colors: [Colors.transparent, Color(0x33000000)],
  stops: [0.5, 1.0], // 仅下半部分
)

// 边角点缀渐变（使用径向渐变 + 偏移）
RadialGradient(
  center: Alignment.topRight,
  radius: 0.5,
  colors: [Color(0x1A000000), Colors.transparent],
)

// 多色渐变叠加（使用 ShaderMask）
ShaderMask(
  shaderCallback: (bounds) => LinearGradient(
    colors: [Color(0xFFFF6B4A), Color(0xFF4ECDC4), Color(0xFFF0C75E)],
  ).createShader(bounds),
  blendMode: BlendMode.overlay,
  child: child,
)
```

### 渐变使用原则

1. 一个页面中渐变类型不超过 3 种，保持视觉统一
2. 渐变颜色过渡要自然，避免硬切
3. 深色模式下降低渐变对比度，避免刺眼
4. 渐变方向应与内容流向一致（如文字从左到右阅读，渐变也可从左到右）
