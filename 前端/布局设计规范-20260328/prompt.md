# 布局设计规范

> 适用平台：Flutter / 移动端应用
> 核心原则：清晰美观、分类明确、呼吸感充足

---

## 信息层级

从高到低分为 4 层：

```
Level 1 - 主内容    │ 标题、核心数据、主要操作按钮
Level 2 - 辅助信息  │ 描述文字、次要数据、辅助操作
Level 3 - 次要内容  │ 时间戳、标签、备注
Level 4 - 装饰元素  │ 背景图案、光效、粒子
```

---

## 网格系统

### 基础单位
- 最小网格单位：**4px**
- 常用间距：8px / 12px / 16px / 24px / 32px / 48px

### 页面边距
| 屏幕尺寸 | 左右边距 | 上下边距 |
|---------|---------|---------|
| 手机（< 600dp） | 16px | 16px |
| 平板（600-840dp） | 24px | 24px |
| 大平板（> 840dp） | 32px | 24px |

### 内容最大宽度
- 手机：满屏宽度 - 边距
- 平板：600px（居中显示）

---

## 视觉分组

功能区域通过以下方式实现视觉分组：

### 1. 留白分组（优先使用）
- 组间间距 ≥ 24px
- 组内间距 8-12px
- 留白是最优雅的分组方式

### 2. 分割线分组
- 线宽：0.5px 或 1px
- 颜色：当前主题的分割线色（通常 10-15% 透明度）
- 与上下内容间距：12-16px

### 3. 色块分组
- 使用卡片包裹相关内容
- 卡片圆角：12-16px
- 卡片内边距：16px
- 卡片间距：12-16px

### 4. 标题分组
- 分组标题字号比内容大 2-4px
- 标题与下方内容间距：8px
- 标题与上方内容间距：24px

## 导航结构

### 顶部导航栏
- 高度：56px（含状态栏区域 64px）
- 材质：亚克力模糊 + 液态玻璃效果
- 内容：标题（居中或左对齐）+ 操作按钮（右侧）
- 返回按钮：左侧

### 底部导航栏
- 高度：64px（含安全区域 80px）
- 项数：3-5 个
- 选中态：图标填充 + 文字强调色 + 液态玻璃高光
- 未选中态：图标描边 + 文字灰色
- 切换动效：图标尺寸变化 + 颜色过渡 + 指示器弹性跟随

### 侧边栏（平板/大屏）
- 宽度：240-280px
- 材质：亚克力模糊面板
- 支持手势展开/收起
- 收起态显示图标，展开态显示图标 + 文字

## 卡片规范

### 基础样式
- 圆角：12-16px
- 阴影：`BoxShadow(color: Colors.black.withOpacity(0.05), blur: 10, offset: Offset(0, 2))`
- 表面材质：亚克力模糊
- 内边距：16px

### 卡片类型

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| 基础卡片 | 标准圆角 + 阴影 | 信息展示 |
| 交互卡片 | 增加点击涟漪效果 | 可点击操作 |
| 列表卡片 | 紧凑内边距 12px | 列表项 |
| 特色卡片 | 渐变边框 + 光效 | 推荐内容、VIP |
| 横幅卡片 | 大圆角 20px + 沉浸式 | 首页 Banner |

### 列表卡片交互
- 支持滑动操作（左滑删除/右滑收藏等）
- 长按进入多选模式
- 拖拽排序（如需要）

## 内容呼吸感

### 文字排版
- 标题与正文间距：8-12px
- 段落间距：16px
- 行高：1.4-1.6 倍字号
- 列表项高度：至少 48px（满足触摸目标）

### 间距节奏
```
页面顶部 ─────── 16px ─────── 标题
标题 ──────────── 24px ─────── 分组标题
分组标题 ──────── 8px ──────── 内容
内容 ──────────── 12px ─────── 内容
内容 ──────────── 24px ─────── 下一分组标题
下一分组标题 ──── 8px ──────── 内容
内容 ──────────── 16px ─────── 页面底部
```

### 留白原则
- 留白不是浪费，是引导视觉流向的关键
- 重要信息周围留白更多，引导视线聚焦
- 密集信息区域使用更大的组间距来分隔
